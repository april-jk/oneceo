## 3. 风险与应对

### 风险 1: 并发扣费导致余额为负

**影响**: 高
**概率**: 中

**应对方案**:
- 使用数据库行锁（`SELECT FOR UPDATE`）或 CAS 更新
- 扣费前检查余额充足
- 设置数据库约束防止负余额

```sql
ALTER TABLE user_credits ADD CONSTRAINT check_balance_non_negative CHECK (balance >= 0);
```

### 风险 2: LLM 响应无 usage 字段

**影响**: 中
**概率**: 低（主要出现在流式响应或异常响应）

**应对方案**:
- 无 usage 时不扣费，但记录异常日志
- 后台可人工核查并补扣
- 长期考虑按请求数兜底计费

### 风险 3: 模型定价变更后历史数据不一致

**影响**: 低
**概率**: 高（定价一定会调整）

**应对方案**:
- token_usage_logs 中保存 pricingSnapshot
- 历史记录展示时使用快照数据
- 统计报表区分「按当时价格」和「按当前价格」

### 风险 4: 余额检查绕过

**影响**: 高
**概率**: 低

**应对方案**:
- LLM Proxy 层内部也做余额校验
- 会话创建和 LLM 调用两处都要检查
- 不允许直接调用上游 API

### 风险 5: 性能影响

**影响**: 中
**概率**: 中

**应对方案**:
- 积分查询走索引（user_id 唯一索引）
- 批量操作时开启连接池
- token_usage_logs 定期归档（如保留 90 天）
- 考虑异步写入（先扣费，后异步写日志）

### 风险 6: 现有会话兼容

**影响**: 低
**概率**: 高

**应对方案**:
- 历史会话无 token 日志，显示「无记录」
- 新会话从上线时刻开始计费
- 用户积分初始化为 0（或赠送体验额度）

### 风险 7: 缓存计费解析错误

**影响**: 中
**概率**: 中（不同提供商格式差异）

**应对方案**:
- LLM Proxy 层对不同提供商的 usage 格式做兼容解析
- OpenAI: `usage.prompt_tokens_details.cached_tokens`
- Anthropic: `usage.cache_creation_input_tokens` + `usage.cache_read_input_tokens`
- 解析失败时回退到普通计费（无缓存），并记录告警日志
- 定期对比上游账单与本地计费记录，确保一致性

### 风险 8: 人民币换算精度问题

**影响**: 低
**概率**: 高

**应对方案**:
- 换算比例可配置（默认 100 积分 = ¥1）
- 显示时保留 2 位小数（¥12.50）
- 仅作展示用，不参与实际计费逻辑
- 支持切换显示/隐藏人民币金额（管理员偏好设置）

## 4. 验收标准

- [ ] 设置菜单可查看历史消费记录
- [ ] 余额不足时无法创建新会话（返回 402）
- [ ] LLM 调用后正确扣减积分
- [ ] 管理后台可查看用户积分列表
- [ ] 管理后台可点击「详情」查看用户积分弹窗
- [ ] 用户详情弹窗含概览/积分历史/使用明细/趋势分析 4 个子 Tab
- [ ] 用户详情弹窗支持跳转用户详情页和会话详情页
- [ ] 管理后台可手动调整用户积分
- [ ] 管理后台可配置模型定价
- [ ] 管理后台可查看平台统计（含人民币换算）
- [ ] 管理后台可查看缓存统计（命中率/节省/创建）
- [ ] 管理后台可查看 Token 使用明细

### 4.2 性能验收

- [ ] 积分查询 < 50ms
- [ ] 扣费操作 < 100ms
- [ ] 消费记录查询 < 200ms（100条以内）

### 4.3 安全验收

- [ ] 并发扣费不会导致负余额
- [ ] 非管理员无法访问计费管理接口
- [ ] 无法绕过余额检查创建会话

### 4.4 缓存计费验收

- [ ] OpenAI 响应正确解析 cached_tokens
- [ ] Anthropic 响应正确解析 cache_creation_input_tokens 和 cache_read_input_tokens
- [ ] 缓存命中时按低价计费（OpenAI 50%，Anthropic 10%）
- [ ] 缓存创建时按高价计费（Anthropic 125%）
- [ ] 管理后台显示 cacheSavings 统计
- [ ] 无缓存信息时回退到正常计费，不报错

- [ ] 管理后台定价配置页只读展示积分/RMB 兑换比例
- [ ] 管理后台定价配置页只读展示 OpenAI/Anthropic 缓存计费比例
- [ ] 计费 smoke 脚本可验证计费管理四个 Tab 和只读规则展示
- [ ] migration/index 回归测试验证 active-only partial unique index
