# 设置 / 通用

## 功能目标

- 站点名称
- 发布状态
- 环境

- 以只读信息卡为主
- 不提供可编辑表单

### 后续阶段

- 支持基础站点信息编辑
- 支持默认入口、发布策略、环境选择等配置

- `latestStatus`
