# 数据库 / 数据浏览与编辑

## 1. 功能目标

这一页是数据库控制台的主工作区，用来直接管理表数据。

用户在这里应该可以完成：

- 选择表
- 查看当前表的数据
- 刷新数据
- 分页浏览
- 直接新增、编辑、删除数据
- 切换列显示

## 2. 页面结构

建议采用左右结构。

### 2.1 左侧表导航

左侧用于承接表级导航，建议包含：

- 表列表
- 当前选中态
- 表来源标签
- 底部 `设置` 按钮

交互要求：

- 点击表名切换右侧表格内容
- 当前表保持高亮
- 表过多时支持纵向滚动

### 2.2 右侧主工作区

顶部工具栏建议包含：

- 当前表名
- `列` 按钮
- `刷新` 按钮
- 更多操作按钮

主体区域建议为数据表格，底部为分页。

## 3. 表格能力

表格至少需要支持：

- 列头展示
- 行选择
- 空态
- 横向滚动
- 分页
- 每页条数切换

建议扩展：

- 排序
- 筛选
- 单元格编辑
- 行级新增与删除

## 4. 数据编辑能力

这部分不是只读。

目标能力：

- 直接新增记录
- 直接编辑现有记录
- 直接删除记录

交互建议：

- 默认使用行级编辑或抽屉编辑
- 高风险删除操作需要确认
- 保存成功后刷新当前页数据

## 5. 数据来源与接口方向

建议后端提供：

- 列表表名接口
- 表结构接口
- 表数据查询接口
- 行新增接口
- 行更新接口
- 行删除接口

查询维度建议支持：

- `tableName`
- `page`
- `pageSize`
- `sort`
- `filters`

## 6. 计划设计方式

### 第一阶段

- 完成表导航 + 表格浏览 + 分页
- 支持刷新和空态

### 第二阶段

- 完成新增、编辑、删除
- 补列显示控制

### 第三阶段

- 补高级筛选
- 补批量操作
- 补关系字段的友好显示

## 7. 审核点

- 数据编辑是否走表格内联编辑，还是右侧抽屉编辑。
- `列` 按钮是否先做列显示控制，再扩展字段信息。
