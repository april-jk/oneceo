### 迭代记录

1. 初次回归
   - 发现刷新后历史回放会多出 `session_started / 会话已创建`，导致页面前后不一致。
   - 修复：前端历史压缩与映射阶段忽略 `session_started`。

2. 二次回归
   - 发现侧栏最近会话预览在刷新前后顺序偶发抖动。
   - 修复：侧栏统一按 `updatedAt` 排序，并将当前会话固定到预览首位。

3. 三次回归
   - 发现“任务完成时”的首份历史消息快照存在落盘延迟，刷新后读取到的消息比完成瞬间更多。
   - 修复：测试脚本改为等待历史消息接口稳定后再采集第一份基准快照。

4. 最终回归
   - 平台能力链路三段快照全部一致，Playwright 通过。

5. 原生历史浏览器验收
   - 发现即时创建 OpenCode 原生历史种子会话在当前环境里不稳定，容易被运行时链路波动放大。
   - 修复：调整浏览器验收策略，改为自动扫描一条已恢复成功的 OpenCode 原生历史会话样本，并校验进入、刷新、重新进入后三份快照和截图一致。

6. 收尾回归
   - 发现重进页面后主区偶发带有 `执行环境已接入（...） · OPENCODE_EVENT` 之类的运行态徽标，导致文本快照比较误报。
   - 修复：测试脚本在对话正文清洗阶段忽略这类瞬时运行态提示，最终两条链路全部通过。
