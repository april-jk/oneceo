## 2. 发现与修复的 Bug

### Bug 1: 管理后台计费导航不显示
**现象**: 管理后台侧边栏未显示「BIL 计费管理」入口。  
**根因**: `App.tsx` 中的 `isSectionKey()` 类型守卫函数遗漏了 `'billing'`，导致 URL 参数 `?section=billing` 被误判为无效，默认回退到 `sandbox`。  
**修复**: `apps/admin_management/web/src/App.tsx:3243-3254` 添加 `|| value === 'billing'`。  
**状态**: 已修复 ✅

### Bug 2: Admin 代理未转发管理员 Cookie
**现象**: 管理后台定价配置、用户积分等页面显示「暂无数据」或「未登录」。  
**根因**: `billing-management-routes.ts` 的代理函数未将浏览器的管理员会话 Cookie 转发给 API Server，导致 API 的 `adminAuthMiddleware` 鉴权失败。  
**修复**: `apps/admin_management/server/routes/billing-management-routes.ts:17-21` 添加 Cookie 转发逻辑。  
**状态**: 已修复 ✅

### Bug 3: 用户积分列表遗漏无记录用户
**现象**: 尚未创建积分记录的用户（balance=0）不在管理后台用户列表中显示。  
**根因**: `internal-billing-routes.ts` 使用 `INNER JOIN userCredits`，排除了没有积分记录的用户。  
**修复**: 改为 `LEFT JOIN` 并从 `appUsers` 为主表查询，`COALESCE` 处理 null 值。  
**状态**: 已修复 ✅

### Bug 4: 注册后积分徽章不显示
**现象**: 用户登录后 Header 的积分徽章未刷新。  
**根因**: `AuthContext.tsx` 的 `login` 和 `register` 函数未在成功后调用 `refreshCredits()`。  
**修复**: 在登录/注册成功后主动调用 `refreshCredits()`。  
**状态**: 已修复 ✅

## 3. 缓存命中策略说明

**缓存比例不是从 API 接口获取的，而是系统固定常量**，硬编码在 `apps/api/src/services/pricing-service.ts` 中：

| Provider | Cache Hit | Cache Creation |
|----------|-----------|----------------|
| OpenAI   | 50%       | 0%             |
| Anthropic| 10%       | 125%           |

管理员无法通过界面修改缓存比例，只能配置模型的 prompt/completion 单价。缓存比例由模型提供商的协议决定，属于系统级策略。
