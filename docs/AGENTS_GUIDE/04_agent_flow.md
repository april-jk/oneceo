# 04 Agent 流程

- Layer 1（入口层）
  - 新建任务：意图识别 + 任务类型判断，路由到对应 Layer 2。
  - 历史会话：复用会话上下文与基础定义，不重复意图识别。

- Layer 2（领域执行层）
  - 软件开发、运营、财务、文案等领域智能体。
  - 由 Layer 1 分流进入具体执行路径。

- Layer 3（执行工具层）
  - 对接 OpenCode / Playwright MCP / n.eko。
  - 统一在编排层做调度与状态机管理。

## 状态机简述

- 状态主线：构思 -> 分析 -> 开发 -> 测试 -> 修复 -> 交付
- 直通模式（Sandbox 直通）：绕过 Layer 1/2/3，仅转发用户与 OpenCode 的消息。
- Altus 接管模式：走完整三层流程，带执行计划与测试闭环。
