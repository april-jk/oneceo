# 02 数据模型与积分换算方案 [20260422-2332已采用]

## 1. 数据库表设计（Drizzle ORM）

### 1.1 user_credits - 用户积分余额表

```typescript
export const userCredits = pgTable(
  'user_credits',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    userId: uuid('user_id')
      .notNull()
      .references(() => appUsers.id, { onDelete: 'cascade' }),
    balance: integer('balance').notNull().default(0),
    totalEarned: integer('total_earned').notNull().default(0),
    totalConsumed: integer('total_consumed').notNull().default(0),
    lastRechargeAt: timestamp('last_recharge_at'),
    createdAt: timestamp('created_at').notNull().defaultNow(),
    updatedAt: timestamp('updated_at').notNull().defaultNow(),
  },
  (table) => ({
    userIdUnique: uniqueIndex('idx_user_credits_user_id').on(table.userId),
  })
);
```

说明：
- balance: 当前可用积分
- totalEarned: 累计获得（含充值、赠送、人工调整）
- totalConsumed: 累计消费
- 通过 totalEarned - totalConsumed 可校验 balance 一致性

### 1.2 credit_transactions - 积分交易记录表

```typescript
export const creditTransactions = pgTable(
  'credit_transactions',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    userId: uuid('user_id')
      .notNull()
      .references(() => appUsers.id, { onDelete: 'cascade' }),
    type: text('type').notNull(),
    amount: integer('amount').notNull(),
    balanceAfter: integer('balance_after').notNull(),

    sourceType: text('source_type'),

    metadataJson: jsonb('metadata_json').notNull().default(sql`'{}'::jsonb`),
    createdAt: timestamp('created_at').notNull().defaultNow(),
  },
  (table) => ({
    userIdIdx: index('idx_credit_transactions_user_id').on(table.userId),
    typeIdx: index('idx_credit_transactions_type').on(table.type),

```

交易类型 type：
- recharge: 充值获得
- consume: LLM 调用消费
- adjust: 管理员人工调整
- refund: 退款（预留）

### 1.3 token_usage_logs - Token 使用明细表

```typescript
export const tokenUsageLogs = pgTable(
  'token_usage_logs',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    userId: uuid('user_id')
      .notNull()
      .references(() => appUsers.id, { onDelete: 'cascade' }),
    sessionId: uuid('session_id')
      .references(() => taskCreationSessions.id, { onDelete: 'set null' }),
    runId: uuid('run_id')
      .references(() => taskSessionRuns.id, { onDelete: 'set null' }),
    model: text('model').notNull(),
    promptTokens: integer('prompt_tokens').notNull().default(0),
    cachedPromptTokens: integer('cached_prompt_tokens').notNull().default(0),
    nonCachedPromptTokens: integer('non_cached_prompt_tokens').notNull().default(0),
    cacheCreationTokens: integer('cache_creation_tokens').notNull().default(0),
    completionTokens: integer('completion_tokens').notNull().default(0),
    totalTokens: integer('total_tokens').notNull().default(0),
    creditsConsumed: integer('credits_consumed').notNull().default(0),
    pricingSnapshot: jsonb('pricing_snapshot').notNull().default(sql`'{}'::jsonb`),
    metadataJson: jsonb('metadata_json').notNull().default(sql`'{}'::jsonb`),
    createdAt: timestamp('created_at').notNull().defaultNow(),
  },
  (table) => ({
    userIdIdx: index('idx_token_usage_logs_user_id').on(table.userId),
    sessionIdIdx: index('idx_token_usage_logs_session_id').on(table.sessionId),
    createdAtIdx: index('idx_token_usage_logs_created_at').on(table.createdAt),
  })
);
```

说明：
- pricingSnapshot: 记录当时的定价配置，防止定价变更后历史数据不一致
- runId: 关联 task_session_runs，支持按 run 维度查询
- cachedPromptTokens: 缓存命中的输入 token（按缓存命中价计费）
- nonCachedPromptTokens: 未缓存的输入 token（按正常输入价计费）
- cacheCreationTokens: 缓存创建的 token（Anthropic 写入计费，OpenAI 无此概念）

### 1.4 model_pricing - 模型定价配置表

```typescript
export const modelPricing = pgTable(
  'model_pricing',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    model: text('model').notNull(),
    modelProvider: text('model_provider').notNull(),
    promptPricePer1kTokens: integer('prompt_price_per_1k_tokens').notNull(),
    completionPricePer1kTokens: integer('completion_price_per_1k_tokens').notNull(),
    isActive: boolean('is_active').notNull().default(true),
    effectiveFrom: timestamp('effective_from').notNull().defaultNow(),
    effectiveUntil: timestamp('effective_until'),
    createdAt: timestamp('created_at').notNull().defaultNow(),
    updatedAt: timestamp('updated_at').notNull().defaultNow(),
  },
  (table) => ({
    modelUnique: uniqueIndex('idx_model_pricing_model').on(table.model),
    activeIdx: index('idx_model_pricing_active').on(table.isActive),
  })
);
```

说明：
- model: 模型标识，如 gpt-4、claude-3-opus-20240229
- modelProvider: openai / anthropic / 其他
- 同模型同一时间只有一条 active 记录（通过唯一索引约束）
- 更新定价时：停用旧记录 + 创建新记录，保留历史
- **缓存比例由系统固定**：OpenAI 命中 50%，Anthropic 命中 10%、创建 125%，管理员无需配置

## 2. 积分换算公式

### 2.1 基础公式

```
creditsConsumed = ceil(
  (nonCachedPromptTokens * promptPricePer1kTokens / 1000) + 
  (cachedPromptTokens * cacheHitPricePer1kTokens / 1000) +
  (cacheCreationTokens * cacheCreationPricePer1kTokens / 1000) +
  (completionTokens * completionPricePer1kTokens / 1000)
)
```

**缓存价格自动计算**（系统固定比例，管理员只需配置基础输入价）：

| 提供商 | 缓存类型 | 比例 | 计算公式 |
|--------|----------|------|----------|
| OpenAI | 命中 | 50% | `promptPrice * 0.5` |
| Anthropic | 命中 | 10% | `promptPrice * 0.1` |
| Anthropic | 创建 | 125% | `promptPrice * 1.25` |

### 2.2 缓存计费说明

**OpenAI 缓存机制**：
- 缓存命中：输入 token 按基础输入价的 **50%** 计费
- 缓存创建：无额外费用（与普通输入同价）
- 响应中标识：`usage.prompt_tokens_details.cached_tokens`
- 管理员只需配置 `promptPricePer1kTokens`，缓存命中价自动计算

**Anthropic 缓存机制**：
- 缓存创建：输入 token 按基础输入价的 **125%** 计费（比普通输入贵 25%）
- 缓存命中：输入 token 按基础输入价的 **10%** 计费
- 响应中标识：`usage.cache_creation_input_tokens` 和 `usage.cache_read_input_tokens`
- 管理员只需配置 `promptPricePer1kTokens`，缓存价自动计算

### 2.3 示例

**示例 1：OpenAI GPT-4o 无缓存**
- prompt: 25 积分 / 1k，completion: 50 积分 / 1k
- 输入 1000 tokens，输出 500 tokens，无缓存
- credits = ceil((1000 * 25 / 1000) + (500 * 50 / 1000)) = 50 积分

**示例 2：OpenAI GPT-4o 缓存命中 60%**
- 输入 1000 tokens（其中 600 缓存命中），输出 500 tokens
- 缓存命中价：12 积分 / 1k（50%）
- credits = ceil((400 * 25 / 1000) + (600 * 12 / 1000) + (500 * 50 / 1000))
       = ceil(10 + 7.2 + 25)
       = 43 积分（节省 7 积分，约 14%）

**示例 3：Anthropic Claude-3 缓存创建后命中**
- 首次调用（创建缓存）：输入 2000 tokens，输出 500 tokens
- 缓存创建价：94 积分 / 1k（125%），completion: 150 积分 / 1k
- credits = ceil((2000 * 94 / 1000) + (500 * 150 / 1000)) = 263 积分

- 二次调用（命中缓存）：输入 2000 tokens（全部命中），输出 500 tokens
- 缓存命中价：8 积分 / 1k（10%）
- credits = ceil((2000 * 8 / 1000) + (500 * 150 / 1000)) = 91 积分（节省 172 积分，约 65%）

## 3. 初始定价建议

### 3.1 基础定价表（管理员只需配置输入/输出单价）

| 模型 | 输入单价 (积分/1k) | 输出单价 (积分/1k) | 提供商 |
|------|-------------------|-------------------|--------|
| gpt-4o | 25 | 50 | openai |
| gpt-4o-mini | 5 | 10 | openai |
| claude-3-opus | 75 | 150 | anthropic |
| claude-3-sonnet | 15 | 30 | anthropic |
| claude-3-haiku | 5 | 10 | anthropic |

**缓存价格自动计算**（系统固定比例，无需配置）：

| 模型 | 缓存命中 | 缓存创建 |
|------|----------|----------|
| gpt-4o | 12.5 (50%) | — |
| claude-3-opus | 7.5 (10%) | 93.75 (125%) |

### 3.2 定价策略

- 1 元人民币约等于 100 积分（仅作参考，实际充值比例可调整）
- 用户注册时赠送 500 积分（新人体验额度）
- **OpenAI 缓存命中按 50% 计费**：适合上下文重复性高的场景
- **Anthropic 缓存创建按 125% 计费，命中按 10% 计费**：适合长上下文多轮对话
