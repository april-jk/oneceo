# Sandbox 创建与使用并在其内部执行命令的记忆

## 目标
记录“创建 sandbox → 下发 OSAC + opencode → 启动 OSAC → 通过 WebSocket 调用 opencode CLI”的完整流程与注意事项。

## 核心环境变量
- KVM_ORCHESTRATOR_URL=http://192.168.10.172:8500
- KVM_ORCH_TOKEN=（Bearer Token）

## 关键路径
- OSAC (Linux amd64, FIX1): `others/osac-linux/osac-linux-amd64_v1.0.fix1`
- opencode: `others/opencode/opencode`
- VM 内目标路径: `/opt/.altus/opencode/`

## 标准流程（推荐）
1) **创建 session**
```bash
POST /v1/sessions  (metadata: owner/purpose)
```

2) **创建 sandbox（主镜像+增量盘）**
```bash
POST /v1/sandboxes
{
  "session_id": "sess_xxx",
  "vm_name": "sandbox_sess_xxx",
  "memory_mb": 2048,
  "vcpus": 2,
  "network": "sandbox-net",
  "os_variant": "ubuntu22.04",
  "auto_bind": true,
  "start": true
}
```

3) **查询 VM IP（确认启动）**
```bash
GET /v1/sandboxes/{session_id}/ip
```

4) **创建端口映射（OSAC 监听 18080）**
```bash
POST /v1/sandboxes/{session_id}/ports
{ "vm_port": 18080, "host_port": <随机>, "protocol": "tcp" }
```
- 建议再调用一次 `GET /ports` 触发 refresh。

5) **下发 OSAC + opencode（二进制）**
```bash
POST /v1/sessions/{session_id}/files (deliveryMode=guest-agent)
- osac-linux-amd64_v1.0.fix1 -> /opt/.altus/opencode/
- opencode -> /opt/.altus/opencode/
```

6) **准备权限与落位**
```bash
/bin/bash -lc "mkdir -p /opt/.altus/opencode/log /opt/.altus/opencode/tmp && \
  mv -f /opt/.altus/opencode/osac-linux-amd64_v1.0.fix1 /opt/.altus/opencode/osac && \
  chmod +x /opt/.altus/opencode/osac /opt/.altus/opencode/opencode"
```

7) **启动 OSAC（后台）**
```bash
/bin/bash -lc "setsid env OSAC_AUTH_TOKEN='<token>' \
  OSAC_LISTEN_ADDR=':18080' \
  OSAC_OPENCODE_PATH='/opt/.altus/opencode/opencode' \
  OSAC_LOG_DIR='/opt/.altus/opencode/log' \
  OSAC_UPDATE_TMP='/opt/.altus/opencode/tmp' \
  OPENCODE_BIN='/opt/.altus/opencode/opencode' \
  OPENCODE_PATH='/opt/.altus/opencode/opencode' \
  /opt/.altus/opencode/osac >> /opt/.altus/opencode/log/osac.log 2>&1 < /dev/null &"
```

8) **验证 OSAC 监听**
```bash
/bin/bash -lc "ss -ltnp | grep 18080 || true; tail -n 5 /opt/.altus/opencode/log/osac.log || true"
```

9) **通过 WebSocket 调用 OSAC**
- WS: `ws://<host_ip>:<host_port>/ws`
- Header: `Authorization: Bearer <OSAC_AUTH_TOKEN>`

示例命令：
```json
{ "type": "EXECUTE_COMMAND", "payload": { "command": "session list --format json --max-count 5" } }
{ "type": "EXECUTE_COMMAND", "payload": { "command": "run --format json \"请输出 Hello from opencode\"" } }
```

## 已知注意事项
- **二进制正确性**：OSAC 必须为 Linux ELF amd64（修复版 `v1.0.fix1`）。
- **磁盘空间**：早期 VM 根盘 2G 易满导致 guest-file-write 失败；需确认扩容已生效。
- **端口映射不稳定**：建议在连接前调用 `GET /ports` 触发 refresh；失败时重建映射再连。
- **capture_output**：后台启动 OSAC 的 guest-exec 请用 `capture_output=false`。
- **session list 空输出**：FIX1 已修复 scanner 错误，但可能仍返回空输出（无 session 时）；如需 `[]` 可让 OSAC 兜底。
