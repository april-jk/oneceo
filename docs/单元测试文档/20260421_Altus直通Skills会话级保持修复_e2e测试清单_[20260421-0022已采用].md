# 20260421 Altus直通 Skills 会话级保持修复 e2e 测试清单 [20260421-0022已采用]

## 1. 测试目标

针对本轮“只做 Altus 直通链路”的 skills 会话级保持修复，验证以下结论是否成立：

1. 直通模式首轮建会话后，skills 状态能正确进入会话级 `sessionSkillState`
2. 后续轮次即使不重复携带 `metadata.skills`，已保存的 resident skills 仍会继续同步到 sandbox
3. contextual resident skill 会按当前上下文决定是否继续挂载，而不是固定永远保留
4. `source=agent` 的内部追问/续跑不会把 resident selections 错误洗掉
5. 真实直通链路至少能打到首轮建会话、OpenCode 桥接与 sandbox provision 阶段；若失败，必须定位失败层级并保留证据

## 5. 详细测试单元清单

### 单元 A：数据库 schema readiness

- 输入：
  - 当前本地 API 所连接数据库
- 预期输出：
  - `task_creation_sessions` 已具备 `metadata_json`
- 验证方式：
  - 执行 `pnpm db:init`
  - 若失败，记录缺失列或迁移报错
- 失败条件：
  - 迁移后 schema 仍不完整

### 单元 B：会话级 skills 状态持久化服务

- 输入：
  - resident selection / explicit selection / contextual binding / sandbox 文件记忆
- 预期输出：
  - `sessionSkillState` 可在 DB 中读写
  - Redis 启用时可命中缓存，未启用时可纯 DB 工作
  - sandbox `skills-memory.json` 可读写并回刷
- 验证方式：
  - 运行：
    - `tests/task-session-skill-state-service.test.ts`
    - `tests/task-session-redis-cache-service.test.ts`
- 失败条件：
  - resident snapshot 丢失
  - Redis 关闭时抛错
  - sandbox 文件记忆无法回写

### 单元 C：直通首轮显式选择 skill 后建立 resident state

- 输入：
  - 首轮用户输入 + 显式 skill 选择
- 预期输出：
  - 建立 `sessionSkillState`
  - 首轮直通 sync 以 resident selections 为准
  - sandbox 收到 resident skills 物化请求
- 验证方式：
  - 运行 `tests/opencode-remote-skill-state.test.ts`
  - 检查 `syncSelectedSkills` mock 入参
- 失败条件：
  - 首轮只看 `metadata.skills`，未写入 resident state

### 单元 D：后续轮次不带 `metadata.skills` 仍可续挂

- 输入：
  - 同一 session 第二轮输入，不携带 `metadata.skills`
- 预期输出：
  - 仍从 `sessionSkillState.residentSelections` 恢复 skills
  - 继续同步到 sandbox
- 验证方式：
  - 运行 `tests/opencode-remote-skill-state.test.ts`
- 失败条件：
  - 第二轮 skill 丢失
  - sandbox sync 入参为空

### 单元 E：contextual resident skill 按上下文退出

- 输入：
  - 上一轮留下 contextual resident skill
  - 当前轮 intent 切换为不再匹配该 skill
- 预期输出：
  - 当前轮 resident selections 去掉该 contextual skill
- 验证方式：
  - 运行 `tests/opencode-remote-skill-state.test.ts`
- 失败条件：
  - contextual skill 永久 sticky

### 单元 F：`source=agent` 内部续跑不洗 resident selections

- 输入：
  - `source=agent`
  - 已有 resident selections
- 预期输出：
  - 不重新按当前内容重算 resident skill
  - 不把已有 resident selections 清空
- 验证方式：
  - 代码检查 + 直通链路定向测试
  - 必要时补充后续针对性用例
- 失败条件：
  - agent 追问导致 resident skills 消失

### 单元 G：sandbox resident 物化与归档恢复基础能力

- 输入：
  - 已解析的 resident skill
  - sandbox archive / restore 过程
- 预期输出：
  - resident skill 能正确物化到 sandbox
  - archive/restore 侧基础能力不破坏 `skills-memory.json` 路径约定
- 验证方式：
  - 运行：
    - `tests/sandbox-skill-sync-service.test.ts`
    - `tests/sandbox-archive.service.test.ts`
- 失败条件：
  - 物化路径错误
  - 归档恢复破坏状态根目录

### 单元 H：真实直通 e2e 首轮建会话

- 输入：
  - WebSocket `opencode_input`
- 预期输出：
  - 收到 `会话已创建`
  - 收到 `OpenCode 已接收输入`
  - 建立 `sessionId / orchestratorSessionId / opencodeSessionId`
- 验证方式：
  - 运行 `pnpm run test:opencode-direct`
  - 检查 `reports/direct-mode-suite-*.json|md`
- 失败条件：
  - 鉴权失败
  - schema 不完整
  - provision 阶段 DB 查询报错
  - accepted/status 未回流

### 单元 I：真实直通 e2e 多轮续聊与 SSE

- 输入：
  - 同一 session 第二轮输入
  - SSE 订阅
- 预期输出：
  - 不新建 session
  - SSE 可持续回放后续 opencode events
  - 历史刷新后消息仍一致
- 验证方式：
  - 运行 `pnpm run test:opencode-direct`
  - 观察 scenario 02-05
- 失败条件：
  - 第二轮 session 漂移
  - SSE 中断
  - persistence refresh 不一致
