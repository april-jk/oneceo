# 20260421 Altus三级记忆系统 Playwright 全链路测试方案

## 目标

验证 Altus 三级记忆系统在真实用户态下的主链路可用性，覆盖：

- 用户级记忆保存、读取、刷新后展示
- 项目级记忆保存、项目内新建会话继承
- session 级记忆在会话运行后生成、刷新后保持、二轮对话后继续更新
- 关联约束与异常面：项目内会话存在时删除项目应被阻止

本轮测试要求：

- 使用 `test@test.com / testtest`
- 尽量单次登录并复用 cookie，不做每条用例清 cookie 重登
- 同时查看 Playwright 页面日志、网络失败日志、服务侧内存快照与 prompt context

## 范围

### 覆盖范围

1. 用户资料中的个性化字段
2. 普通项目的项目级记忆字段
3. 项目条目右侧箭头直接创建项目内会话
4. Altus managed run 启动时的三级记忆组装
5. session 运行后的 session memory 回写
6. 页面刷新后的会话连续性

### 不覆盖范围

1. Redis 开关关闭场景
2. sandbox 归档恢复后的跨 sandbox 恢复
3. skills 记忆本身功能回归
4. 多项目并发切换

## 测试单元

### 01 用户级记忆保存与 UI 展示

- 输入：
  - preferredName
  - occupation
  - location
  - responsePreferences
- 期望：
  - `/api/auth/me` 返回值与写入一致
  - 个性化设置面板展示与写入一致

### 02 项目级记忆保存与项目列表展示

- 输入：
  - 项目名称
  - context
  - guidelines
  - operatingRules
  - executionManual
- 期望：
  - `/api/task-creation/projects/:projectId` 返回 `altusProjectMemory`
  - 侧边栏出现目标项目
  - 项目条目右侧箭头可直接进入项目内新会话

### 03 项目内首轮会话继承三级记忆

- 输入：
  - 从项目箭头入口进入新会话
  - 首轮消息要求模型说明称呼与项目代号
- 期望：
  - 新会话 `projectId/projectName` 正确绑定
  - 首轮 run 完成
  - `altusMemoryContextService.buildPromptSectionForRun()` 中同时存在 user / project / session 三层内容

### 04 session 级记忆生成与刷新保持

- 输入：
  - 首轮完成后刷新页面
  - 继续第二轮消息，要求基于上一轮继续回答
- 期望：
  - 会话 URL 与 `task_creation_session_id` 保持一致
  - 消息历史保留
  - `taskSessionAltusMemoryService.getSessionAltusMemory()` 的 `version` 增长
  - `summary.goal`、`latestOutcome`、`workingNotes` 非空且合理

### 05 项目删除阻断

- 输入：
  - 在会话仍归属项目时调用删除项目
- 期望：
  - 返回 `409`
  - 报错文本为“当前项目下仍有关联会话，请先移出这些会话后再删除项目”

## 边界与失败判定

以下任一情况判为失败：

- 页面出现 `pageerror`
- 关键链路请求出现 `requestfailed`
- `/api/auth/me`、`/api/task-creation/projects/:id`、`/api/altus-managed/...` 返回异常状态
- prompt context 未包含用户级或项目级记忆
- session memory 未生成或版本未更新
- 刷新后会话丢失
- 删除项目未被阻断

## 验证方法

### UI 证据

- Playwright 页面断言
- 设置面板字段值断言
- 侧边栏项目和箭头入口断言
- 会话刷新后页面与输入框断言

### 接口证据

- `/api/auth/me`
- `/api/task-creation/projects/:projectId`
- `/api/task-creation/sessions/:sessionId/messages`
- `/api/altus-managed/sessions/:sessionId/runs/latest`

### 服务侧证据

- `altusMemoryContextService.buildPromptSectionForRun()`
- `taskSessionAltusMemoryService.getSessionAltusMemory()`

## 执行说明

- 采用单条 Playwright spec 执行，避免多次清理 cookie
- 首次登录后复用同一 `BrowserContext`
- 测试完成后恢复用户个性化、删除测试会话、删除测试项目，保持测试账号整洁
