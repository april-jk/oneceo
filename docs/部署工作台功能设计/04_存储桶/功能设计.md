# 存储桶功能设计[暂时不开发]

## 1. 功能定位

“存储桶”用于承接未来的平台对象存储能力，主要服务于：

- 用户上传文件
- 媒体资源
- 构建产物与静态资源分离

当前决策：

- 页面入口保留
- 当前版本不进入开发
- 仅保留文档和产品占位

## 2. 页面结构

建议结构：

- 存储状态卡
- 推荐用途说明
- 当前可见状态
- 场景规划卡

## 3. 当前状态

当前应用访问与默认域名已接入部署工作台，但对象存储尚未成为正式能力。

因此当前页面建议：

- 保留入口
- 明确“未启用”
- 用场景卡说明未来用途
- 不进入当前开发排期

补充说明：

- 2026-04-30 已新增候选方案 [Altus 数据库与存储桶工具化接入方案 [尚未采用]](../06_生成应用部署基线/23_Altus数据库与存储桶工具化接入方案_%5B尚未采用%5D.md)。
- 在该候选方案被用户明确采用前，本页仍维持“暂时不开发”的当前状态。
- 若候选方案被采用，本页需要同步升级为真实项目存储桶资源页，而不是继续保留占位说明页。

## 4. 计划设计方式

### 第一阶段

- 只读说明页
- 表达对象存储尚未开通
- 不做接口、不做交互实现、不做后端能力接入

### 第二阶段

- 平台托管存储桶创建
- 公开读 / 私有读策略
- 生命周期与清理策略

### 第三阶段

- 与上传组件、附件流、图片处理链路打通

## 5. 审核点

- 存储桶是否继续只保留入口，不进入当前开发。
- 未来是否把“文件存储”统一归到这个页面，而不是单独系统设置。
