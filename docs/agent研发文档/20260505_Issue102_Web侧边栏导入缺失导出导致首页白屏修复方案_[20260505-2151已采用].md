# 20260505 Issue102 Web侧边栏导入缺失导出导致首页白屏修复方案 [20260505-2151已采用]

## 1. 背景与现象

Issue #102 反馈用户访问 `http://localhost:3000/` 时首页白屏，浏览器控制台报错：

```text
Uncaught SyntaxError: The requested module '/src/lib/shared-manual-projects.ts' does not provide an export named 'readSidebarExpandedState'
```

当前仓库 HEAD 上，`Sidebar.tsx` 仍然从 `shared-manual-projects.ts` 导入 `readSidebarExpandedState`，但该导出已在提交 `506c3394` 中被删除。

## 2. 根因

这不是数据问题，也不是浏览器缓存问题，而是一次明确的前端 ESM 导入契约断裂：

1. `apps/web/client/src/components/Sidebar.tsx` 依赖 `readSidebarExpandedState` 来恢复侧边栏展开态；
2. `apps/web/client/src/lib/shared-manual-projects.ts` 不再导出该函数；
3. 浏览器在解析模块阶段直接抛出 `SyntaxError`；
4. React 主应用在渲染前就被阻断，于是首页白屏。

## 3. 约束

1. 不允许引入兼容性分支或双实现并存；
2. 不允许修改 `Sidebar.tsx` 的展开态数据结构来规避问题；
3. 必须保持既有本地存储键与字段名不变：
   - `expandedProjectGroups`
   - `expandedProjects`
   - `expandedManagers`
4. 修复必须覆盖坏 JSON、字段类型错误和数组脏数据，避免再次因为本地存储异常导致初始化抛错。

## 4. 修复方案

最短路径修复：

1. 在 `apps/web/client/src/lib/shared-manual-projects.ts` 补回并导出 `readSidebarExpandedState(raw, key, fallback)`；
2. 函数行为固定为：
   - `raw` 为空时返回 `fallback`
   - JSON 解析失败时返回 `fallback`
   - 目标字段不是数组时返回 `fallback`
   - 数组中仅保留非空字符串项
3. 不改 `Sidebar.tsx` 的调用方式，只恢复原本需要的公共 helper；
4. 在 `apps/web/client/src/tests/shared-manual-projects.test.ts` 增加回归测试，锁住上述边界。

## 5. 验证

至少执行：

```bash
pnpm --filter web exec vitest run client/src/tests/shared-manual-projects.test.ts
pnpm --filter web check
```

验收标准：

1. `Sidebar.tsx` 的导入重新成立；
2. `web check` 不再报 `TS2305`；
3. helper 单测覆盖正常数据、坏 JSON、错误字段类型、数组脏数据；
4. 首页不再因该模块导入错误白屏。
