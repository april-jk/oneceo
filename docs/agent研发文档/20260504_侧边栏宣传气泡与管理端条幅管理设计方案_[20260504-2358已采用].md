# 20260504_侧边栏宣传气泡与管理端条幅管理设计方案_[20260504-2358已采用]

## 1. 背景与目标

当前侧边栏在“通知”区域之上缺少可运营的信息承载位，无法进行活动公告、产品引导、功能推荐等触达。  
本方案新增“侧边栏气泡位”，并在管理端提供“宣传条幅管理”独立页面，支持图文与轮播配置，实现可配置、可控、可灰度的运营展示能力。

核心目标：

1. 在用户端侧边栏新增一个固定预留气泡区域（位于侧边栏下方、通知上方）。
2. 支持单图文卡片与多图轮播两种展示模式。
3. 管理端新增独立配置页面：`侧边栏 -> 宣传条幅管理`，并包含标签页：
   - 首页气泡
   - 侧边栏气泡（本次实现重点）
4. 支持发布控制、时间窗控制、展示优先级、点击跳转与基础统计。

## 2. 术语定义

- 宣传位（placement）：一个展示位置，例如 `home_bubble`、`sidebar_bubble`。
- 条幅（banner）：一个可发布的运营内容实体，包含文案、图片、跳转、展示规则。
- 素材项（item）：条幅内的单个展示项；当条幅类型为轮播时，包含多个素材项。

## 3. 用户端展示设计（侧边栏气泡）

### 3.1 位置与层级

- 位置：侧边栏底部区域，通知入口上方。
- 层级：同属于侧边栏内容区域，视觉层级低于主导航，高于纯装饰分隔元素。
- 占位策略：无数据时不占高度，避免空洞。

### 3.2 展示模式

1. 单卡模式（single）
   - 显示一张图片（可选）+ 标题 + 副标题（可选）+ 关闭按钮（可选）。
2. 轮播模式（carousel）
   - 支持多素材左右切换/自动播放（可配置间隔）。
   - 支持底部分页指示点。

### 3.3 交互规则

- 点击卡片：根据配置执行跳转（站内路由或外链）。
- 关闭行为：
  - 若配置允许关闭，则本地记忆关闭状态（按条幅 ID + 用户 ID）。
  - 关闭后在有效期内不再展示，除非条幅版本更新。
- 自动播放：
  - 默认 5 秒切换，可配置 3~10 秒。
  - 鼠标悬停暂停（桌面端）。

### 3.4 响应式与降级

- PC 常规宽度按 1 行卡片设计；窄宽场景收缩文案长度。
- 图片加载失败时显示纯文案卡片，不阻断展示。
- 当轮播素材不足 2 条时自动降级为单卡模式。

## 4. 管理端设计：宣传条幅管理（独立页面）

### 4.1 导航结构

- 一级入口：`侧边栏`
- 二级页面：`宣传条幅管理`
- 页面内标签页：
  - `首页气泡`
  - `侧边栏气泡`（本次实现）

### 4.2 列表能力

列表字段建议：

1. 条幅名称
2. 展示位置（首页/侧边栏）
3. 展示类型（单卡/轮播）
4. 状态（草稿/已发布/已下线/已过期）
5. 生效时间（开始/结束）
6. 优先级
7. 最近更新时间

支持筛选：

1. 状态筛选
2. 时间范围筛选
3. 关键词搜索（名称）

支持操作：

1. 新建
2. 编辑
3. 发布/下线
4. 预览
5. 删除（草稿允许，已发布需先下线）

### 4.3 编辑表单（侧边栏气泡）

基础字段：

1. 条幅名称（必填）
2. 展示位置（固定为 `sidebar_bubble`）
3. 展示类型（single/carousel）
4. 优先级（整数，越大越优先）
5. 生效时间窗（开始时间、结束时间）
6. 是否允许关闭
7. 关闭后再次展示策略（版本更新后重置/固定不再展示）

内容字段：

1. 标题（必填）
2. 副标题（可选）
3. 图片（可选，支持上传与 URL）
4. 跳转类型（站内路由/外部链接/不跳转）
5. 跳转目标（按类型校验）
6. CTA 文案（可选）

轮播附加字段：

1. 素材项列表（至少 2 条）
2. 自动播放开关
3. 自动播放间隔（秒）

校验规则：

1. 发布时间必须落在有效期内。
2. 外链必须为 `https://`。
3. 轮播素材数量不足时禁止保存为轮播。

## 5. 数据模型设计

建议新增两张表（避免与通知系统强耦合）：

1. `ui_promo_banners`
2. `ui_promo_banner_items`

`ui_promo_banners` 字段：

1. `id` (uuid)
2. `name` (varchar)
3. `placement` (enum: `home_bubble` | `sidebar_bubble`)
4. `display_type` (enum: `single` | `carousel`)
5. `status` (enum: `draft` | `published` | `offline`)
6. `priority` (int)
7. `allow_dismiss` (bool)
8. `dismiss_reset_on_version` (bool)
9. `start_at` (timestamp nullable)
10. `end_at` (timestamp nullable)
11. `version` (int, default 1)
12. `created_by` / `updated_by`
13. `created_at` / `updated_at`

`ui_promo_banner_items` 字段：

1. `id` (uuid)
2. `banner_id` (fk)
3. `sort_order` (int)
4. `title` (varchar)
5. `subtitle` (varchar nullable)
6. `image_url` (text nullable)
7. `cta_text` (varchar nullable)
8. `link_type` (enum: `internal` | `external` | `none`)
9. `link_target` (text nullable)
10. `is_active` (bool)
11. `created_at` / `updated_at`

可选统计表（后续迭代）：

1. `ui_promo_banner_events`（曝光、点击、关闭）

## 6. 读取与命中规则

用户端读取接口按以下顺序返回“当前可展示条幅”：

1. `placement = sidebar_bubble`
2. `status = published`
3. 时间窗命中（`start_at/end_at`）
4. 按 `priority DESC, updated_at DESC` 排序
5. 取第一条

若命中条幅：

1. single：返回首个有效 item
2. carousel：返回有效 items（按 `sort_order ASC`）

## 7. API 设计（管理端 + 用户端）

管理端 API：

1. `GET /admin/promo-banners?placement=sidebar_bubble&status=...`
2. `POST /admin/promo-banners`
3. `PUT /admin/promo-banners/:id`
4. `POST /admin/promo-banners/:id/publish`
5. `POST /admin/promo-banners/:id/offline`
6. `DELETE /admin/promo-banners/:id`
7. `GET /admin/promo-banners/:id/preview`

用户端 API：

1. `GET /app/ui/promo-banners/active?placement=sidebar_bubble`
2. `POST /app/ui/promo-banners/:id/events`（点击/关闭/曝光）

## 8. 权限与安全

1. 管理端仅 `admin_users` 且具备内容配置权限角色可操作。
2. 外链统一白名单校验（域名可配置）。
3. 图片上传走既有媒体服务，防止任意文件注入。
4. 用户端接口只返回“已发布且生效”的最小字段。

## 9. 埋点与指标

基础指标：

1. 曝光量（impression）
2. 点击量（click）
3. CTR
4. 关闭率（dismiss rate）

维度：

1. 条幅 ID
2. 展示位置
3. 日期
4. 用户类型（可选）

## 10. 边界条件与异常处理

1. 条幅无有效 item：不展示，记录告警日志。
2. 条幅时间窗失效：自动不返回。
3. 图片资源 404：降级纯文案展示。
4. 链接非法：后端拒绝发布。
5. 多条同优先级冲突：按更新时间兜底排序。

## 11. 实施范围（本次）

本次明确交付：

1. 管理端新增“宣传条幅管理”独立页面与标签页框架。
2. 完整实现“侧边栏气泡”标签页的列表、创建、编辑、发布/下线。
3. 用户端侧边栏接入气泡渲染（支持单卡 + 轮播）。
4. 支持图片与轮播配置。
5. 支持基础点击/关闭事件上报。

本次不做（后续可选）：

1. 首页气泡完整渲染逻辑（仅保留标签页与占位结构）。
2. 高级 A/B 实验与人群定向。

## 12. 验收标准

1. 在管理端创建并发布侧边栏气泡后，用户端刷新可见。
2. 单卡与轮播两种模式都可稳定展示。
3. 条幅过期后自动消失。
4. 关闭后遵循配置策略，不重复骚扰用户。
5. 标签页包含“首页气泡、侧边栏气泡”，且本次侧边栏气泡可全流程使用。

## 13. 风险与注意事项

1. 若将宣传位与通知位耦合，会加重后续维护成本；建议独立数据模型。
2. 若不做外链白名单，存在运营误配风险。
3. 轮播图片尺寸若不约束，容易出现布局抖动，需在前端固定容器比例。

## 20260505 重构说明（已纳入当前采用方案）

- 发布逻辑改为“同一展示位可存在多条已发布条幅”，用户侧自动聚合为轮播展示，不再要求手动在单条幅内设置轮播模式。
