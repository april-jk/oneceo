# 07 云端导入下线方案 [20260522-1735已采用]

## 1. 采用结论

本轮已确认：

1. 输入框附件加号菜单中的“从云端添加”功能整体下线。
2. 当前 `Excel / DOC / PDF` 等附件解析能力按现状继续使用，本轮不调整该能力。
3. 本轮只处理云端导入链路下线，不同时推进新的附件解析改造。

## 2. 删除范围

### 前端

- 删除加号菜单中的“从云端添加”入口
- 删除远程 URL 对话框
- 删除前端远程附件抓取 helper
- 删除对应文案与 UI 测试

### 后端

- 删除 `POST /api/task-creation/attachments/fetch`
- 删除 `remote-attachment-service.ts`
- 删除对应单测与路由测试

## 3. 保留范围

以下能力必须保持不变：

1. 本地文件添加
2. 技能附件添加
3. 现有 `Excel / DOC / PDF` 等附件解析能力维持现状，暂不修改
4. managed 输入统一走 `/api/altus-managed/inputs`
5. `uploads/` 附件落点与现有文本/图片处理逻辑

## 4. 验收口径

1. 加号菜单中不再出现“从云端添加”。
2. 本地文件添加仍可正常工作。
3. 技能附件添加仍可正常工作。
4. 仓库中不再保留云端导入的前后端实现与测试。
