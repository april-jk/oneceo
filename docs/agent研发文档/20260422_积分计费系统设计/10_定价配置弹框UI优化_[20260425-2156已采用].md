# 管理后台计费管理"新建/更新定价配置"与详情弹框 UI 优化 [20260425-2156已采用]

## 1. 背景与目标

当前计费管理定价配置表单与详情弹框依赖通用 `user-management-modal` + 大量 inline style，外观偏粗糙，缺乏专用感。本次优化目标：将通用弹框改为专用、专业、紧凑的定价配置弹框，提升管理员操作体验。

## 2. 改动范围

- **前端组件**：`apps/admin_management/web/src/components/BillingManagementSection.tsx`
- **样式文件**：`apps/admin_management/web/src/styles.css`
- **不涉及**：后端 API 契约

## 3. 设计要点

### 3.1 专用弹框类名
- 为定价表单弹框使用专用 class `pricing-form-modal`，不再只依赖 `user-management-modal` + inline style。

### 3.2 移除/减少内联样式
- 提取为 CSS 类，包括：
  - 弹框内部布局（flex、overflow 等）
  - section 间距与 padding
  - 底部操作区布局

### 3.3 主体结构
- **标题区**：定价配置、更新定价配置（创建新版本）/新建定价配置、简短说明。
- **表单体**：模型范围、基础定价、缓存计费三个轻量 section。不用厚重卡片感，用分隔线和 section 标题。
- **底部操作区**：取消 + 主按钮。

### 3.4 按钮规范
- 底部主按钮使用 `primary-btn`。
- 取消按钮使用 `secondary-btn`。

### 3.5 关闭按钮
- 顶部关闭按钮改为轻量 X 图标按钮（优先）。
- 使用 icon-btn 风格，而非 secondary-btn "关闭"。

### 3.6 表单布局
- 固定两列为主：输入单价和输出单价并排。
- 生效时间可跨列或单列，布局稳定。
- 窄屏（<=640px）改单列。

### 3.7 标签精简
- 例如"输入单价"替代"输入单价（正整数 credits / 1k tokens）"。
- 单位说明用 small 或辅助文本，不要长标签。

### 3.8 缓存计费说明
- 改为提示条（info-tip / alert-bar），强调 provider 生效范围。
- 提示条样式使用柔和的背景色，不要用大面积俗套渐变。

### 3.9 字段级校验反馈
- 至少对输入单价/输出单价/缓存命中比例/缓存创建比例展示错误文案或 error class。
- 不要只禁用按钮。
- 校验规则：
  - 输入单价：正整数，>0
  - 输出单价：正整数，>0
  - 缓存命中比例：0~100%
  - 缓存创建比例：0~1000%

### 3.10 更新模式上下文提示
- 更新模式下增加简短提示：当前模型/提供商不可编辑，新保存会创建新版本，不回写历史 usage。
- 使用提示条样式，与缓存计费说明区分。

### 3.11 响应式
- 保持 responsive，窄屏改单列。

### 3.12 禁止项
- 禁止 gradient text、玻璃拟态、粗侧边色条、大面积俗套渐变。

### 3.13 定价详情弹框

- 定价详情弹框与新建/更新弹框使用同一套专用外壳，避免回退到通用 `user-management-modal`。
- 标题区保留模型名与说明，右上角使用轻量 `×` 关闭按钮。
- 主体按“审计摘要 / 计费规则”分组：
  - 审计摘要展示模型、提供商、状态、生效时间。
  - 计费规则展示输入单价、输出单价、缓存命中、缓存创建。
- 计费数字使用等宽数字与独立单位标签，方便管理员核对。
- 底部操作区将危险操作与主操作分区：删除在左侧，关闭与更新定价在右侧；更新定价使用 `primary-btn`。

## 4. CSS 新增类清单

| 类名 | 作用 |
|------|------|
| `pricing-form-modal` | 弹框专用外壳，控制宽度/最大高度 |
| `pricing-form-modal-header` | 标题区布局 |
| `pricing-form-modal-body` | 表单体，滚动区域 |
| `pricing-form-section` | 单个 section，分隔线 |
| `pricing-form-section-title` | section 标题 |
| `pricing-form-grid` | 两列表单网格 |
| `pricing-form-field` | 字段包装 |
| `pricing-form-field-error` | 错误状态 |
| `pricing-form-field-hint` | 辅助文本 |
| `pricing-form-tip` | 提示条（缓存说明、更新提示） |
| `pricing-form-actions` | 底部操作区 |
| `pricing-form-modal-close` | 顶部 X 关闭按钮 |
| `pricing-detail-section` | 定价详情分组 |
| `pricing-detail-grid` | 定价详情 kv / 指标网格 |
| `pricing-detail-metric` | 定价详情计费指标 |
| `pricing-detail-actions` | 定价详情底部操作区 |

## 5. 验收标准

- [ ] 弹框使用专用 CSS 类，inline style 显著减少。
- [ ] 主按钮使用 `primary-btn`，取消使用 `secondary-btn`。
- [ ] 顶部有轻量 X 关闭按钮。
- [ ] 表单两列布局稳定，窄屏改单列。
- [ ] 标签精简，单位说明用辅助文本。
- [ ] 缓存计费说明改为提示条。
- [ ] 字段级校验有错误文案/error class。
- [ ] 更新模式有上下文提示条。
- [ ] 不引入新依赖，API 契约不变。
- [ ] Type-check 通过。
- [ ] 定价详情弹框使用专用布局，详情中的更新入口为主按钮，删除入口有危险操作视觉。

## 6. 风险

- 样式冲突：需确保新增类名不与现有类名冲突。
- 删除操作视觉层级需明确，但不能改变删除接口与确认逻辑。
