# 设置 / GitHub

## 当前状态

该子页当前只保留前端 UI 占位，不进入具体功能设计。

后续如重新开启设置设计，再统一重写本页。

## 功能目标

说明平台托管源码镜像与自动发布链路，而不是让最终用户直接管理底层仓库。

## 计划设计方式

### 当前阶段

- 仅展示“平台托管同步中”这类状态
- 展示最近同步版本与触发方式
- 不展示敏感仓库细节和供应链密钥

### 后续阶段

- 如有必要，可补充只读仓库概览
- 仍然不建议把底层 Git 仓库操作完全暴露给最终用户

## 当前建议的数据来源

- 当前 deployment 的 commit 信息
- 发布历史
- 平台部署账号中的源码同步状态

## 审核点

- 当前是否确认只保留 UI 占位。
