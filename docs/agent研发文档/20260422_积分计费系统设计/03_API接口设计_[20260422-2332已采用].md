# 03 API接口设计 [20260422-2332已采用]

## 1. 用户端接口

### 1.1 GET /api/billing/credits - 查询当前用户积分余额

**请求**: 无需参数（从 session 解析 userId）

**响应**:
```json
{
  "balance": 1234,
  "totalEarned": 5000,
  "totalConsumed": 3766
}
```

### 1.2 GET /api/billing/transactions - 查询消费记录（分页）

**查询参数**:
- page?: number (默认 1)
- limit?: number (默认 20, 最大 100)
- type?: 'consume' | 'recharge' | 'adjust'

**响应**:
```json
{
  "items": [
    {
      "id": "uuid",
      "type": "consume",
      "amount": -50,
      "balanceAfter": 1234,
      "description": "会话: 开发一个网站",
      "createdAt": "2026-04-22T14:30:00Z",
      "sourceId": "session-uuid"
    }
  ],
  "total": 156,
  "page": 1,
  "limit": 20
}
```

### 1.3 GET /api/billing/session/:sessionId/usage - 查询单个会话积分消耗

**响应**:
```json
{
  "sessionId": "uuid",
  "totalCredits": 320,
  "totalTokens": 5400,
  "cacheSavings": 45,
  "modelBreakdown": [
    {
      "model": "gpt-4o",
      "promptTokens": 2000,
      "cachedPromptTokens": 1200,
      "nonCachedPromptTokens": 800,
      "completionTokens": 800,
      "credits": 120,
      "cacheSavings": 16
    },
    {
      "model": "claude-3-sonnet",
      "promptTokens": 1500,
      "cachedPromptTokens": 0,
      "cacheCreationTokens": 1500,
      "completionTokens": 1100,
      "credits": 200,
      "cacheSavings": 0
    }
  ]
}
```

说明：
- cacheSavings: 相比无缓存计费节省的积分（管理后台用，用户端不显示）
- cachedPromptTokens: 缓存命中 token 数
- nonCachedPromptTokens: 未缓存 token 数
- cacheCreationTokens: 缓存创建 token 数（Anthropic 特有）

### 2.2 POST /api/internal/billing/users/:userId/adjust - 手动增加积分

**请求体**:
```json
{
  "amount": 1000,
  "reason": "活动补偿",
  "adminId": "admin-uuid"
}
```

说明：
- amount 当前仅支持大于 0 的整数，表示人工增加积分

- 需要记录 adminId 用于审计

```json

  "transactionId": "uuid",
  "balanceAfter": 2234,
  "amount": 1000
}
```

### 2.4 POST /api/internal/billing/pricing - 新增/更新模型定价

**请求体**:
```json
{
  "model": "gpt-4o",
  "modelProvider": "openai",
  "promptPricePer1kTokens": 25,
  "completionPricePer1kTokens": 50
}
```

说明：
- 如果该模型已有 active 定价，则自动停用旧记录并创建新记录
- 如果该模型无 active 定价，直接创建
- **缓存价格自动计算**：OpenAI 命中 50%，Anthropic 命中 10%/创建 125%
- 管理员只需配置基础输入/输出单价

### 2.5 DELETE /api/internal/billing/pricing/:id - 停用定价

说明：
- 软删除，设置 effectiveUntil = now() 和 isActive = false
- 不影响历史记录

### 3.2 LLM 调用后扣费（含缓存解析）

位置: `apps/api/src/connectors/llm-proxy-connector.ts`

```typescript
// 伪代码
async function afterLLMCall(userId, sessionId, runId, response) {
  const usage = response.usage;
  if (!usage) return; // 无 usage 时不扣费，但记录异常
  
  const pricing = await getActivePricing(response.model);
  
  // 解析缓存 token（不同提供商格式不同）
  const cacheInfo = parseCacheTokens(usage, response.modelProvider);
  
  // 计算积分消耗
  const creditsConsumed = calculateCreditsWithCache(usage, pricing, cacheInfo);
  
  // 原子操作：扣减余额 + 写交易记录 + 写 token 日志
  await db.transaction(async (trx) => {
    await trx.update(userCredits)
      .set({ 
        balance: sql`balance - ${creditsConsumed}`,
        totalConsumed: sql`total_consumed + ${creditsConsumed}`
      })
      .where(eq(userCredits.userId, userId));
    
    await trx.insert(creditTransactions).values({
      userId,
      type: 'consume',
      amount: -creditsConsumed,
      balanceAfter: sql`(SELECT balance FROM user_credits WHERE user_id = ${userId})`,
      sourceId: sessionId,
      sourceType: 'session',
      description: `LLM调用: ${response.model}`
    });
    
    await trx.insert(tokenUsageLogs).values({
      userId,
      sessionId,
      runId,
      model: response.model,
      promptTokens: usage.prompt_tokens,
      cachedPromptTokens: cacheInfo.cachedPromptTokens,
      nonCachedPromptTokens: cacheInfo.nonCachedPromptTokens,
      cacheCreationTokens: cacheInfo.cacheCreationTokens,
      completionTokens: usage.completion_tokens,
      totalTokens: usage.total_tokens,
      creditsConsumed,
      pricingSnapshot: pricing
    });
  });
}

// 缓存 token 解析函数
function parseCacheTokens(usage, provider) {
  if (provider === 'openai') {
    const cachedPromptTokens = usage.prompt_tokens_details?.cached_tokens || 0;
    return {
      cachedPromptTokens,
      nonCachedPromptTokens: usage.prompt_tokens - cachedPromptTokens,
      cacheCreationTokens: 0 // OpenAI 无此概念
    };
  } else if (provider === 'anthropic') {
    const cacheCreationTokens = usage.cache_creation_input_tokens || 0;
    const cachedPromptTokens = usage.cache_read_input_tokens || 0;
    return {
      cachedPromptTokens,
      nonCachedPromptTokens: usage.input_tokens - cacheCreationTokens - cachedPromptTokens,
      cacheCreationTokens
    };
  }
  
  return {
    cachedPromptTokens: 0,
    nonCachedPromptTokens: usage.prompt_tokens || usage.input_tokens || 0,
    cacheCreationTokens: 0
  };
}

// 带缓存的积分计算函数
// 缓存价格按系统固定比例自动计算
function calculateCreditsWithCache(usage, pricing, cacheInfo) {
  // 系统固定缓存比例
  const CACHE_RATIOS = {
    openai: { hit: 0.5, creation: 0 },
    anthropic: { hit: 0.1, creation: 1.25 }
  };
  
  const ratio = CACHE_RATIOS[pricing.modelProvider] || { hit: 0, creation: 0 };
  
  const cacheHitPrice = pricing.promptPricePer1kTokens * ratio.hit;
  const cacheCreationPrice = pricing.promptPricePer1kTokens * ratio.creation;
  
  return Math.ceil(
    (cacheInfo.nonCachedPromptTokens * pricing.promptPricePer1kTokens / 1000) +
    (cacheInfo.cachedPromptTokens * cacheHitPrice / 1000) +
    (cacheInfo.cacheCreationTokens * cacheCreationPrice / 1000) +
    (usage.completion_tokens * pricing.completionPricePer1kTokens / 1000)
  );
}
```

### 3.3 并发安全

方案 A: 数据库行锁（推荐）
```typescript
await trx.execute(sql`SELECT * FROM user_credits WHERE user_id = ${userId} FOR UPDATE`);
```

方案 B: CAS (Compare-And-Swap)
```typescript
const result = await trx.update(userCredits)
  .set({ balance: sql`balance - ${creditsConsumed}` })
  .where(and(
    eq(userCredits.userId, userId),
    sql`balance >= ${creditsConsumed}`
  ))
  .returning();

if (result.length === 0) {
  throw new Error('积分不足或并发冲突');
}
```

## 4. 错误码

| 状态码 | 错误码 | 说明 |
|--------|--------|------|
| 402 | INSUFFICIENT_CREDITS | 积分不足 |
| 400 | INVALID_PRICING | 模型无定价配置 |
| 400 | INVALID_CACHE_INFO | 缓存信息解析失败 |
| 409 | CONCURRENT_DEDUCTION | 并发扣费冲突 |
