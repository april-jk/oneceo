# 20260410 Issue39 预览窗口文件模块稳定性修复方案 [20260410-1035已采用]

## 1. 问题背景

Issue #39 目标是修复预览窗口“文件模块”在以下场景的不稳定表现：

1. 文件打开/切换偶发空白或内容错位。
2. HTML/网页类文件在预览窗口可见性不稳定（只能看源码，不可直接预览页面）。
3. 刷新/重进后，当前文件与视图状态无法恢复。
4. 回放与实时消息触发树刷新后，文件面板状态偶发丢失。

## 2. 现状核验（代码证据）

1. 前端 `OpencodePreviewPanel` 里 `handleFileSelect` 无并发请求保护，快速切换文件时旧请求可回写新状态，存在竞态。
2. `selectedPath/previewTab/previewOpen/previewWorkspacePath` 仅存在内存态，没有持久化，刷新或重进后必然丢失。
3. 后端 `detectPreviewType` 对文本文件仅区分 `markdown/text`，`html` 被当成普通 `text`，前端只走 `<pre>` 渲染，不支持页面预览。
4. `workspace/raw/*` 已存在，可作为 iframe/raw 预览源，但前端未接入 HTML 预览路径。
5. 消息与回放里经常携带绝对路径（如 `/home/user/opencode/workspaces/<sessionId>/index.html`），前端直接透传后在 `workspace/file` 链路被当作相对路径再次拼接 `workspaceRoot`，导致“文件存在但预览空白/读取失败”。
6. `workspace/dir` 在 live 根目录为空时会走 message history 回退，但历史路径未按 `workspaceRoot` 还原为相对路径，导致回退结果经常为空。

## 3. 修复目标

1. 文件切换稳定：禁止旧请求覆盖新选择。
2. HTML 文件可稳定“源码/页面”双视图预览。
3. 刷新/重进后恢复：
   - 预览开关状态
   - 当前 tab（files/changes/debug/deployment）
   - 当前选中文件路径（files tab）
4. 目录刷新与消息回放期间保持选中文件一致，若文件不存在给出明确反馈。

## 4. 非目标

1. 不改业务权限模型（仍按当前会话用户鉴权）。
2. 不引入新的预览服务或外部存储。
3. 不扩展到 Office/PDF 之外的新文件解析引擎。

## 5. 方案设计（最短路径）

### 5.1 工作区路径映射收口（核心）

1. 前端统一把“绝对工作区路径”归一化为“会话相对路径”。
2. 覆盖入口：
   - `Home.openWorkspacePreview`
   - `OpencodePreviewPanel` 的外部选中文件与 diff fallback tree
   - `AltusRunReplayDrawer` 与 `AltusArtifactPreviewCard`
3. 后端在 `workspace/file` 与 `workspace/raw/*` 读取前统一做相对路径解析：
   - 同会话绝对路径自动映射
   - 非法路径与跨会话路径拒绝
4. `workspace/dir` 的 message history 回退构建时，同样按 `workspaceRoot` 归一化路径，确保根目录回退可见。

### 5.2 文件请求竞态收口

1. 在 `OpencodePreviewPanel` 增加递增请求序号（或 `AbortController`）。
2. 每次 `handleFileSelect(path)` 发请求前记录当前 token；响应返回时仅在 token 匹配时 `setFileData/setFileError`。
3. 切换到新文件时立即清空旧 `fileData` 的展示态，避免误显示上一文件内容。

### 5.3 预览状态持久化与恢复

1. 在 `Home.tsx` 引入预览状态缓存键（按 `sessionId` 维度）。
2. 持久化字段：
   - `previewOpen`
   - `previewTab`
   - `previewWorkspacePath`
3. 在 session 切换与页面初始化时恢复；无效路径恢复失败时自动降级到 files tab 空态并提示。

### 5.4 HTML 预览能力补齐

1. 后端 `detectPreviewType`：对 `text/html` 或 `html/htm` 返回 `html`（新增预览类型）。
2. `workspace/file` 返回 `previewType='html'`。
3. 前端 `FilePreview` 对 `html` 文件提供两种视图：
   - `Source`（现有 `<pre>`）
   - `Preview`（`<iframe src={workspaceRawUrl}>`）
4. iframe 加载失败时显示可操作提示（“在新标签页打开”）。

### 5.5 刷新/重进一致性

1. `refreshTree("auto")` 后若 `selectedPath` 存在，自动做一次安全 revalidate（文件仍存在则刷新内容，不存在则清空并提示）。
2. 路由重进（`/session/:id?view=history`）时，若存在持久化路径，优先恢复并触发一次 `handleFileSelect`。

### 5.6 源头落库归一化（补强）

1. 在 `task-creation-session.dao` 的消息元数据落库清洗阶段，统一把以下字段按会话维度归一化为相对路径：
   - `filePaths[]`
   - `fileChanges[].path`
   - `path`
   - `targetPath`
2. 归一化规则：
   - 优先剥离 `workspacePath/workspaceRoot` 前缀
   - 同时支持 `/workspaces/<sessionId>/...` 与 `workspaces/<sessionId>/...` 两种绝对样式
   - 拒绝 `..` 越界样式，防止脏路径继续扩散
3. `workspace/dir` 目录接口也接入同一解析逻辑，允许“传入工作区根路径”映射为根目录 `''`，避免目录链路成为剩余薄弱点。

## 6. 验证方案

### 6.1 单元/组件验证

1. 新增/补充 `OpencodePreviewPanel` 相关测试：
   - 快速切换 A->B，A 慢返回不覆盖 B。
   - HTML 文件显示 `Preview` 视图，且 iframe URL 正确。
2. 新增 API 路由测试：
   - `workspace/file` 接收同会话绝对路径仍能正确映射到相对路径读取。
   - `workspace/dir` message history 回退可把绝对路径映射为根目录可见文件。

### 6.2 页面级回归（Playwright）

至少覆盖一次完整链路：

1. 打开预览 -> 选中文件 -> 切换 tab。
2. 刷新页面后验证当前文件与 tab 恢复。
3. 新开页面重进同一 session，验证恢复一致。
4. HTML 文件验证 iframe 可见且可切回源码。

### 6.3 数据库层实证（新增）

1. 执行临时会话写入验证：向 `conversation_messages.metadata` 写入包含绝对路径的 `filePaths/fileChanges/path`。
2. 直接查询数据库确认新写入结果已是相对路径（如 `src/index.ts` / `index.html` / `README.md`）。
3. 验证结束后删除临时会话，避免测试数据残留。

## 7. 风险与规避

## 8. Altus Replay 文件选择补充（2026-04-22）

在 `Altus Actions` 的文件视图里又确认了一条同类问题：

1. `AltusRunReplayDrawer` 自己维护 `selectedFilePath`，同时 `useWorkspaceFilePreviewState` 内部还有一份 `selectedPath`；
2. 点击左侧其他文件时，只更新了 preview hook 内部状态，Drawer 自己的 `selectedFilePath` 没有同步；
3. hook 又会基于外部传入的旧 `selectedWorkspacePath` 重新触发一次 `handleFileSelect`，于是右侧预览被拉回默认 HTML 文件，看起来像“其他文件无法点击”。

本轮补充收口：

1. Drawer 中文件点击必须同时更新外层 `selectedFilePath` 与 preview hook；
2. “按当前 action 默认产物文件回填选中态”的逻辑只允许在切换 `run / toolCallId` 时触发；
3. 同一 action 内用户手动切到其他文件后，必须保留该选择，不能在后续 render 中被默认 HTML 产物覆盖。

1. 风险：持久化状态与后端实际文件树不一致。
   - 规避：恢复时做 exists/reload 校验，不存在即降级并提示。
2. 风险：iframe 预览跨源或 CSP 问题。
   - 规避：使用同源 `workspace/raw/*` 路径，失败时提供新标签页回退。
3. 风险：历史消息包含不同会话的绝对路径。
   - 规避：后端相对路径解析仅接受当前会话 `workspaceRoot`，其余路径丢弃。

## 8. 交付标准（对应 Issue #39）

1. 文件预览稳定打开/切换，无随机空白。
2. 刷新/重进后当前文件与视图状态一致。
3. 大文件/异常文件展示明确加载或错误反馈。
4. 提供至少一次页面级回归验证记录（含刷新与重进）。
