# 存储桶功能设计[20260430-1326已采用]

## 1. 功能定位

“存储桶”用于承接未来的平台对象存储能力，主要服务于：

- 用户上传文件
- 媒体资源
- 构建产物与静态资源分离

当前决策：

- 页面入口升级为真实 Railway Bucket 资源页
- 用户侧存储桶只使用 Railway Bucket
- 创建资源必须由 Altus managed tool 或用户按钮显式触发

## 2. 页面结构

建议结构：

- 存储状态卡
- 推荐用途说明
- 当前可见状态
- 场景规划卡

## 3. 当前状态

当前应用访问与默认域名已接入部署工作台，对象存储升级为当前会话 Railway Environment 下的项目资源能力。

因此当前页面建议：

- 未启用时显示用途说明和“启用存储桶”
- 已启用时显示 Bucket 名称、endpoint、publicUrl、accessKeyId、secretAccessKey
- accessKeyId、secretAccessKey 默认掩码，用户主动点击后才显示明文
- 展示自动注入应用服务的环境变量键名

补充说明：

- 2026-04-30 已采用 [Altus 数据库与存储桶工具化接入方案 [20260430-1326已采用]](../06_生成应用部署基线/23_Altus数据库与存储桶工具化接入方案_%5B20260430-1326已采用%5D.md)。
- 本页已从占位说明升级为真实项目存储桶资源页，用户侧存储桶固定使用 Railway Bucket。

## 4. 计划设计方式

### 4.0 读取链路补充（2026-05-01）

- 存储桶状态接口已接入会话级 Redis 读缓存（按 `userId + sessionId` 隔离）。
- 显式启用存储桶与删除文件后，接口侧需要失效对应会话缓存，确保列表与状态刷新为最新结果。
- 未显式开启 Redis 时，继续走原有实时读取链路，不改变当前主流程行为。

### 第一阶段

- 只读说明页
- 表达对象存储尚未开通
- 不做接口、不做交互实现、不做后端能力接入

### 第二阶段

- 平台托管存储桶创建
- 公开读 / 私有读策略
- 生命周期与清理策略

### 第三阶段

- 与上传组件、附件流、图片处理链路打通

## 5. 审核点

- 存储桶是否继续只保留入口，不进入当前开发。
- 未来是否把“文件存储”统一归到这个页面，而不是单独系统设置。
