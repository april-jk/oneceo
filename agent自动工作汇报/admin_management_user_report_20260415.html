这轮联调里修掉的真实问题

Playwright 打开“用户管理”后，详情链路一开始会触发数据库错误。原因是 `sandbox_execution_environments.metadata ->> 'taskSessionId'` 返回的是文本，而 `task_creation_sessions.id` 是 UUID，直接比较会失败。

修正方式是把 `task_creation_sessions.id` 显式转成 `text` 再比较。修复后，真实后台已能正常看到用户 `thweki` 的会话数、对话数和 Sandbox 数。
