# 20260418 用户态双语页面 Playwright 回归测试方案 [20260418-1838已采用]

## 1. 测试目标

验证本次用户态多语言边界修复后，平台主要用户页面在中文、英文两种语言下满足以下要求：

1. 页面可正常访问，不出现白屏、明显报错或致命渲染失败。
2. UI 文案可随语言切换正确变化。
3. AI 生成内容、业务内容、示例内容、消息流内容不因语言切换被二次翻译或重写。
4. 关键布局在桌面端下不出现明显遮挡、重叠、截断或错位。
5. 设置中的语言切换可对全局用户态 UI 生效，并保持页面可用。

## 2. 测试依据

1. `docs/agent研发文档/20260418_用户态多语言内容边界修复方案_[20260418-1227已采用].md`
2. `docs/AGENTS_GUIDE/05_系统调试与测试指南.md`
3. 当前 `apps/web/client/src/App.tsx` 中用户态路由定义

## 3. 测试范围

本次覆盖以下主要用户态页面：

1. `/login`
2. `/register`
3. `/home`
4. `/search`
5. `/library`
6. `/projects`
7. `/project/:id`
8. `/manager-node`
9. `/manager-view`
10. `/agent-project`
11. `/ceo-view`
12. `/task/:projectId/:managerId/:taskId`

说明：

1. 受鉴权保护页面通过测试账号登录后访问。
2. 本次不覆盖管理端。
3. 本次重点验证桌面端主路径，不扩展到移动端专项适配。

## 4. 测试单元清单

### 单元 A：站点启动与基础可访问性

- 输入：本地启动 `apps/web` 开发服务。
- 预期输出：浏览器可打开站点首页，前端资源加载成功。
- 边界条件：端口冲突时需切换可用端口。
- 失败条件：服务无法启动、首页白屏、首屏控制台致命错误。
- 验证方式：本地开发服务启动 + Playwright 打开页面。

### 单元 B：登录页双语显示

- 输入：访问 `/login`，分别切换中文、英文。
- 预期输出：标题、输入框、按钮、跳转提示随语言变化；布局稳定。
- 边界条件：切换后 URL、表单状态不导致页面异常。
- 失败条件：文案未切换、错位、按钮不可见。
- 验证方式：Playwright 页面操作与截图观察。

### 单元 C：注册页双语显示

- 输入：访问 `/register`，分别切换中文、英文。
- 预期输出：注册表单、验证码发送按钮、说明文案正确切换；布局稳定。
- 边界条件：验证码流程相关按钮在未提交情况下可见且无 JS 报错。
- 失败条件：文案缺失、覆盖、明显断行异常、脚本错误。
- 验证方式：Playwright 页面操作与截图观察。

### 单元 D：登录后语言切换全局生效

- 输入：使用测试账号登录，在设置中切换语言。
- 预期输出：侧边栏、设置、用户态通用 UI 标签切换语言。
- 边界条件：切换后当前页保持可操作。
- 失败条件：切换无效、部分核心 UI 不刷新、页面崩溃。
- 验证方式：Playwright 登录后打开设置并切换语言。

### 单元 E：Home 页面内容边界

- 输入：在 `/home` 分别查看中文、英文下的主界面。
- 预期输出：
  1. UI 标签随语言变化；
  2. 快捷操作、按钮、设置项按语言展示；
  3. 消息流中的既有内容或状态内容不被切换语言后二次翻译。
- 边界条件：空态与有侧栏状态均可见。
- 失败条件：消息胶囊被改写、AI 内容被翻译、布局明显错位。
- 验证方式：Playwright 观察页面与语言切换前后对比。

### 单元 F：Manager/Project/Task/CEO/Agent 页面内容边界

- 输入：访问 `/projects`、`/project/1`、`/manager-node`、`/manager-view`、`/ceo-view`、`/agent-project`、`/task/1/m1/t1`，分别在中英文下查看。
- 预期输出：
  1. 页面标题、按钮、统计标签等 UI 文案正确切换；
  2. mock 项目名、经理名、任务名、交付内容、消息内容保持原始内容，不因语言切换改变；
  3. 页面主体无重叠、明显截断或空白异常。
- 边界条件：部分页面含弹窗/抽屉/卡片，需要验证主要入口可见。
- 失败条件：内容字段被翻译、双头像等明显结构问题复发、布局异常。
- 验证方式：Playwright 路由访问、必要按钮点击、截图观察。

### 单元 G：设置页语言入口与账户页稳定性

- 输入：登录后打开设置，检查“设置/账户/模型设置”等核心页签，在中英文下切换。
- 预期输出：设置结构正常，语言选择可用，账户页与二级页布局稳定。
- 边界条件：设置弹窗在不同语言下可滚动、可切换页签。
- 失败条件：设置项缺失、语言选择器无效、页面结构异常。
- 验证方式：Playwright 打开设置并逐项检查。

### 单元 H：控制台与网络错误巡检

- 输入：执行上述页面访问与切换流程。
- 预期输出：无新的致命控制台错误；不存在因语言切换引入的资源加载错误。
- 边界条件：允许第三方开发提示类非阻断 warning，但需记录。
- 失败条件：未捕获异常、500、白屏相关错误。
- 验证方式：Playwright 收集 console / pageerror / failed request。

## 5. 测试数据与前置条件

1. 使用本地 `apps/web` 开发服务。
2. 需要一个可登录的测试用户；若本地接口允许则通过注册接口创建。
3. 默认以桌面端视口执行回归。

## 6. 本次不做什么

1. 不把本次页面回归扩大为 API 深度链路测试。
2. 不把本次双语回归扩大为管理端多语言测试。
3. 不把本次桌面端回归扩大为完整移动端专项适配验收。

## 7. 输出要求

最终输出需包含：

1. 实际覆盖页面清单
2. 中英文切换结果
3. 发现的问题与修复结果
4. 仍需人工关注的剩余风险
