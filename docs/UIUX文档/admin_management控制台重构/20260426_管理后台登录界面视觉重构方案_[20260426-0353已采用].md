## 3. 当前问题

1. **视觉仍偏基础**  
   当前是深色 Hero + 白色表单卡的基础双栏结构，缺少成熟后台入口的品牌场景和层次。

2. **品牌资产缺失**  
   登录页没有使用独立品牌辅助素材；`public/favicon.svg` 已有 teal + blue 方向，但登录页色彩没有系统延展。

3. **后台语境不足**  
   左侧只展示标题、说明和三个标签，没有表达“运行、治理、审计、配置”的控制台场景。

4. **表单密度被后置规则压缩**  
   登录按钮和输入框在前段样式中较舒展，但后置全局紧凑规则会让登录页变得像后台表格控件，正式入口感不足。

5. **loading 态弱**  
   `authStatus === 'loading'` 时只有单卡片，没有继承未登录页的品牌结构。

6. **视觉 token 不稳定**  
   主题主色、favicon 渐变、登录按钮、Hero 背景的颜色来源不够统一。

## 4. 设计目标

1. 重构登录页为更成熟的 OneCEO 管理后台入口。
2. 保留现有管理员认证链路、字段、API 与 session 行为。
3. 使用克制的企业级控制台视觉，不做营销页、不做 AI 海报化。
4. 让登录表单成为首屏最明确的操作焦点。
5. 优化输入框、按钮、错误态、loading 态、禁用态与响应式布局。
6. 可以使用 gpt-image-2 生成一张轻量品牌辅助素材，但素材只服务登录页左侧场景，不进入表单区域。
7. 素材失败或未加载时，登录页仍保持完整可用。

## 5. 非目标

1. 不修改 `/api/admin/auth/*` 接口。
2. 不修改 cookie、session、管理员权限模型。
3. 不新增第三方 UI 框架。
4. 不重构管理后台主界面。
5. 不把登录页做成官网、宣传海报或产品营销页。
6. 不在生成图片中放文字、口号、Logo、真实人物或机器人形象。
7. 不用图片替代关键信息和表单交互。

## 6. 视觉方向

### 6.1 场景句

OneCEO 管理员在白天办公室或夜间值守时进入后台，需要一个安静、可信、可快速登录的控制台入口；页面应该像企业级运维控制台的门禁，而不是营销展示页。

### 6.2 色彩方向

1. 延续 favicon 的 teal + blue 线索。
2. 背景使用 tinted slate / blue / teal，避免纯黑纯白。
3. 主按钮使用品牌 teal，焦点环使用 blue/teal 的低透明混合。
4. 左侧素材低对比，右侧登录卡高可读。

### 6.3 布局方向

桌面端保留双栏，但重新定义层次：

```text
Auth Shell
├─ Brand Scene Panel
│  ├─ ONECEO 管理控制台
│  ├─ 平台管理与运维控制台
│  ├─ 授权管理员说明
│  ├─ 低对比品牌素材：治理拓扑 / 审计流 / 沙箱节点
│  └─ 3 个业务标签：平台治理 / 运行监控 / 配置管理
└─ Login Panel
   ├─ 管理员入口
   ├─ 管理员登录
   ├─ 登录名
   ├─ 密码
   ├─ 错误提示
   └─ 登录按钮
```

### 6.4 响应式方向

1. `>= 920px`：双栏布局。
2. `< 920px`：单栏布局，Hero 压缩为顶部品牌场景区。
3. `< 640px`：优先登录卡，Hero 只保留简短品牌识别和标签。
4. 输入框和按钮高度不被全局紧凑规则压扁。

## 15. 登录框点击阻断修正 [20260426-0353已采用]

用户反馈“点不了登录框”。复核后确认为背景层与伪元素存在层级覆盖风险：

1. `.auth-background::before / ::after` 用于遮罩与网格，但 z-index 高于登录布局时可能拦截点击。
2. 修正要求：
   - `.auth-shell` 增加 `isolation: isolate`。
   - `.auth-background` 固定为 `z-index: 0` 且 `pointer-events: none`。
   - `.auth-background::before / ::after` 均 `pointer-events: none`。
   - `.admin-auth-layout-single` 固定为 `position: relative; z-index: 1`。
3. 验收：登录名、密码输入框与登录按钮必须可点击、可聚焦、可提交。
