# 对话管理与智能体管理整合方案 [尚未采用]

> 本文档描述将「智能体管理」功能整合进「对话管理」的设计方案。

---

## 1. 背景与问题

当前 admin_management 控制台存在两个高度重叠的模块：

- **对话管理**：完整会话索引（表格、搜索、筛选、排序）+ 6 标签详情面板
- **智能体管理**：服务健康看板 + 会话统计卡片 + 阶段分布 Tab + 能力列表

两个模块的数据源完全一致（都来自 Task Creation 会话），只是展示视角不同：
- 对话管理是**操作视角**——管理员日常排查、查看会话详情
- 智能体管理是**运营视角**——关注服务健康、阶段分布、能力可用性

重叠点包括：

| 重叠项 | 智能体管理 | 对话管理 |
|--------|-----------|----------|
| 会话列表 | 阶段下最近 6 条 | 完整表格 |
| 会话统计 | 5 个数字卡片 | 顶部摘要条 |
| 阶段信息 | Tab 分组 | 筛选下拉框 |
| 状态信息 | 状态构成 | 状态列 + 筛选 |

---

## 2. 目标

1. **消除重复**：两套会话列表逻辑合并为一处
2. **导航扁平**：侧边栏减少一个入口
3. **视角自由切换**：同一份数据，操作视角和运营视角一键切换
4. **阶段信息前置**：把最有价值的"阶段分组"直接放到索引视图，提升日常效率

---

## 3. 整合方案

### 3.1 总体架构

```
对话管理（保留为唯一入口）
├── 视图切换器：[索引视图] [运营概览]
│
├── 索引视图（现有 + 增强）
│   ├── 阶段 Tab 条（新增）
│   ├── 会话摘要条（现有）
│   ├── 筛选工具栏（现有，阶段筛选移除，改为 Tab 条）
│   └── 会话表格（现有）
│
└── 运营概览视图（新增，来自原智能体管理）
    ├── 服务健康卡片
    ├── 会话统计卡片
    ├── 阶段分布面板
    └── 智能体能力面板
```

### 3.2 侧边栏变更

**删除**「智能体管理」导航项，只保留「对话管理」。

### 3.3 索引视图增强

在现有会话索引的筛选区域上方，**增加阶段 Tab 条**：

```
┌──────────────────────────────────────────────────────────────┐
│  全部(42) │ 信息收集(8) │ 等待补充(3) │ 生成方案(5) │ 执行中(12) │ 已完成(14)
└──────────────────────────────────────────────────────────────┘
```

- 点击 Tab 即按阶段筛选会话列表
- 与现有"状态/阶段"下拉筛选互斥：选择阶段 Tab 时，下拉筛选自动重置为"全部状态与阶段"
- 阶段 Tab 的数据来自对话管理现有接口（已包含 stage 字段），无需额外 API

### 3.4 运营概览视图

把原智能体管理的全部内容迁移为对话管理的第二个视图：

#### 服务健康卡片（顶部紧凑栏）
- 平台接口在线/离线
- 智能体服务在线/离线
- 最近检查时间

#### 会话统计卡片（保留 5 个数字）
- 总会话、待确认、进行中、失败、可用能力数

#### 阶段分布面板
- 阶段 Tab 列表 + 选中阶段的详情
- 阶段内状态构成
- 最近 6 条会话（可点击跳转详情）

#### 智能体能力面板
- 能力名称、接入方式、可用状态

### 3.5 数据流设计

**运营概览视图的数据来源**：
- 会话统计 → 复用对话管理的 `conversationSessions` 和 `conversationSummary` 状态
- 阶段分布 → 在对话管理加载会话列表时，同时计算阶段分布（前端计算，无需额外 API）
- 服务健康 → 新增一个轻量级 API（复用现有的 `oneceoApi.health()` + `oneceoApi.getAgentHealth()`）
- 能力列表 → 硬编码为前端常量（目前只有 Task Creation Agent 是 available，其余都是 planned）

**因此可以删除 `AgentManagementService` 和 `/api/agent-management/*` 路由**。

## 7. 健康检查 API 设计

由于删除了 `AgentManagementService`，前端需要直接调用两个现有 API 来获取服务健康：

```typescript
// 新增轻量 hook 或直接在 effect 中调用
const [serviceHealth, setServiceHealth] = useState({
  oneceoApi: { online: false, timestamp: null as string | null },
  agentApi: { online: false, message: '未知', timestamp: null as string | null },
});

useEffect(() => {
  if (conversationView !== 'overview') return;
  
  Promise.allSettled([
    api.health(),
    api.getAgentHealth(),
  ]).then(([apiHealth, agentHealth]) => {
    setServiceHealth({
      oneceoApi: {
        online: apiHealth.status === 'fulfilled' && apiHealth.value.status === 'ok',
        timestamp: apiHealth.status === 'fulfilled' ? apiHealth.value.timestamp : null,
      },
      agentApi: {
        online: agentHealth.status === 'fulfilled',
        message: agentHealth.status === 'fulfilled' ? agentHealth.value.message : '智能体接口不可用',
        timestamp: agentHealth.status === 'fulfilled' ? agentHealth.value.timestamp : null,
      },
    });
  });
}, [conversationView]);
```

## 8. 阶段分布计算（前端）

```typescript
function buildStageDistribution(sessions: ConversationSession[]) {
  const map = new Map<string, {
    stageKey: string;
    label: string;
    value: number;
    statuses: Map<string, number>;
    recentSessions: ConversationSession[];
  }>();

  for (const session of sessions) {
    const key = session.stage || 'unknown';
    const bucket = map.get(key) || {
      stageKey: key,
      label: conversationStageLabel(key),
      value: 0,
      statuses: new Map(),
      recentSessions: [],
    };
    bucket.value += 1;
    bucket.statuses.set(session.status, (bucket.statuses.get(session.status) || 0) + 1);
    bucket.recentSessions.push(session);
    map.set(key, bucket);
  }

  return Array.from(map.values())
    .map(item => ({
      ...item,
      statusSummary: Array.from(item.statuses.entries())
        .map(([label, value]) => ({ label: statusLabel(label), value }))
        .sort((a, b) => b.value - a.value),
      recentSessions: item.recentSessions
        .sort((a, b) => Date.parse(b.updatedAt) - Date.parse(a.updatedAt))
        .slice(0, 6),
    }))
    .sort((a, b) => b.value - a.value);
}
```
