## 2. 页面层级（三层嵌套）

### L1：用户索引页

**功能**：以用户为索引，展示所有有审计记录的用户列表。

**布局**：
- 顶部：统计摘要卡片（总用户数、今日请求数、错误数、平均耗时）
- 筛选栏：
  - 搜索（用户邮箱、ID、名称）
  - 时间范围（最近 1h / 24h / 7d / 30d）
- 主表格列：
  | 列 | 说明 |
  |---|---|
  | 用户 | 邮箱 + ID（点击跳转 L2） |
  | 最近请求 | 最后一条请求的时间 + 路径 |
  | 请求总数 | 筛选时间范围内的请求数 |
  | 错误数 | 4xx/5xx 响应计数 |
  | 会话数 | 关联的 task_creation_sessions 数量 |
  | 操作 | 「查看详情」按钮 |

### L2：用户审计详情页

**功能**：展示单个用户的全部审计活动，分为两个 Tab：

#### Tab A：HTTP 请求日志

**布局**：
- 返回按钮（回到 L1）+ 用户标识标题
- 筛选栏：
  - 路径关键词
  - 方法（GET/POST/PUT/DELETE）
  - 状态码（成功 2xx / 客户端错误 4xx / 服务端错误 5xx）
  - 时间范围
- 请求列表表格：
  | 列 | 说明 |
  |---|---|
  | 时间 | `createdAt` 格式化 |
  | 方法 | HTTP method，彩色标签 |
  | 路径 | `path` + `queryString` 摘要 |
  | 状态 | 响应码，彩色标签 |
  | 耗时 | `durationMs` ms |
  | 会话 | 关联的 `taskSessionId`（可跳转 L3） |
  | 操作 | 「查看详情」按钮 |

- 点击「查看详情」展开侧滑面板（非弹窗）：
  - **结构化视图**：
    - 请求概览：method、path、status、duration
    - 请求头：表格展示 key-value（脱敏后）
    - 请求体摘要：关键字段卡片
    - 响应体摘要：关键字段卡片
  - **原始 JSON 视图**：可折叠的 `<pre>` 代码块，展示完整脱敏后的 headers 和 summary

#### Tab B：会话列表

**布局**：
- 用户创建的会话列表
- 每行展示：会话标题、状态、创建时间、trace 统计（LLM 请求数、工具调用数、错误数）
- 点击会话进入 L3

### L3：会话 AI Trace 时间线

**功能**：展示单个会话的 `session_api_traces` 完整时间线。

**布局**：
- 返回按钮（回到 L2）+ 会话标题
- 筛选栏：
  - trace 类型（全部 / LLM 请求 / 工具调用 / 服务 API / 连接器 API）
  - 时间范围
- 时间线视图（主展示方式）：
  - 垂直时间线，每个节点为一个 trace
  - 节点颜色区分类型（LLM=蓝色、工具=绿色、服务=灰色、连接器=紫色）
  - 节点内展示：时间、类型标签、简要描述
  - 点击节点展开详情面板：
    - **结构化视图**：
      - 基本信息：model、provider、toolName、endpoint
      - Token 消耗：prompt / completion / total
      - 耗时：durationMs
      - 请求/响应摘要卡片
    - **原始 JSON 视图**：可折叠的完整 trace JSON

- 表格视图（备选）：
  - 提供切换到表格的按钮
  - 列：sequence、time、type、model/tool、status、duration、tokens

## 4. URL State 设计

```typescript
type AuditViewState = {
  view: 'users' | 'user-detail' | 'session-trace';
  userId?: string;           // L2/L3 时使用
  sessionId?: string;        // L3 时使用
  // 筛选条件
  timeRange?: '1h' | '24h' | '7d' | '30d';
  method?: string;
  status?: string;
  pathQuery?: string;
  traceType?: string;
};
```

URL 参数映射：
- `audit_view`: users | user | trace
- `audit_user`: 用户 ID
- `audit_session`: 会话 ID
- `audit_range`: 时间范围
- `audit_method`: HTTP 方法
- `audit_status`: 状态码
- `audit_q`: 路径搜索关键词
- `audit_trace_type`: trace 类型
