# 2026-04-09 admin_management 治理与可用性二期测试方案 [20260409-0605已采用]

## 1. 测试目标

验证 `apps/admin_management` 本轮治理改造在真实浏览器与最小代码检查下可用，且行为符合采用方案。

## 2. 测试单元

1. 登录页与管理员登录。
2. 默认首页是否为 `Sandbox 管理`。
3. Sandbox 模板详情中的别名设置、别名可用性检查、保存反馈。
4. 全局遮罩与 toast：`查看`、`刷新`、`保存` 等动作。
5. 审计日志筛选与详情查看。
6. 智能体管理阶段分布中文化与详细输出。
7. 技能管理二级菜单中文化。
8. 对话管理主要功能可用性、无效入口、布局响应。
9. 最小类型检查：`npm --prefix apps/admin_management run type-check`。

## 3. 预期输入与预期输出

### 3.1 登录

- 输入：管理员账号密码。
- 预期输出：进入后台首页，出现已登录管理员信息。

### 3.2 默认首页

- 输入：登录成功后首次进入后台。
- 预期输出：首屏为 `Sandbox 管理`，导航高亮位于 Sandbox。

### 3.3 模板别名闭环

- 输入：打开模板详情，输入候选别名，执行检查与保存。
- 预期输出：检查结果能判断可用/占用；保存成功后详情与列表刷新；失败时 toast 显示具体错误。

### 3.4 全局反馈

- 输入：点击 `查看`、`刷新`、`保存` 等需要等待的动作。
- 预期输出：页面出现背景虚化和加载提示；请求失败时右上角弹出错误信息。

### 3.5 审计日志

- 输入：筛选条件与查看详情动作。
- 预期输出：列表按条件过滤；详情弹窗展示单条记录与关联记录。

### 3.6 智能体管理

- 输入：进入智能体管理。
- 预期输出：任务阶段分布使用中文；可展开查看更细会话信息。

### 3.7 技能管理

- 输入：进入技能管理并打开详情。
- 预期输出：二级菜单和关键工作区以中文为主，保留必要技术标识说明。

### 3.8 对话管理

- 输入：进入对话管理，切换会话、查看主工作区与右侧 inspector。
- 预期输出：主要功能可访问；无效功能已删除或降级；布局在桌面与中等宽度下无明显错位。

## 4. 边界条件与失败条件

1. 后端接口不可达时，需要明确 toast 或页面错误信息。
2. 模板别名占用时，需要给出结构化判断而不是裸 JSON 堆叠。
3. 审计日志无记录时，筛选区仍应可用且空态明确。
4. 对话管理无数据或某些子接口失败时，不应导致整页不可用。

## 5. 验证方式

1. Playwright Interactive 审阅并保存截图到 `output/playwright/`。
2. 本地手工查看关键 DOM 和交互。
3. `npm --prefix apps/admin_management run type-check`。
