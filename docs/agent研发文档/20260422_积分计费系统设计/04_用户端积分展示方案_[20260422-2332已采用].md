# 04 用户端积分展示方案 [20260422-2332已采用]

## 1. Header 显示剩余积分

### 1.1 位置

在 `apps/web/client/src/components/Header.tsx` 中，UserMenu 左侧增加积分显示组件。

### 1.2 设计

```tsx
// CreditBadge.tsx
export function CreditBadge({ balance }: { balance: number }) {
  return (
    <div className="flex items-center gap-1.5 px-3 py-1.5 rounded-full bg-amber-50 border border-amber-200 text-amber-700 text-sm font-medium">
      <Diamond className="w-4 h-4 text-amber-500" />
      <span>{balance.toLocaleString()} 积分</span>
    </div>
  );
}
```

### 1.3 数据获取

```tsx
// 在 AuthContext 中增加积分查询
const { user, credits, refreshCredits } = useAuth();

// 进入页面时获取
useEffect(() => {
  refreshCredits();
}, []);

// WebSocket 推送积分变动时更新
useWebSocket('credit_update', (data) => {
  refreshCredits();
});
```

### 1.4 状态变化提示

当积分变动时（如会话结束后），显示 toast 提示：
```
本次会话消耗 50 积分，剩余 1,184 积分
```

## 2. 会话界面显示当前消耗

### 2.1 位置

在会话详情页（`/session/:sessionId`）的以下位置之一：
- 方案 A: 消息输入框上方（小字提示）
- 方案 B: 侧边栏底部（固定区域）
- 方案 C: 顶部标题栏右侧

推荐方案 A，不占用固定空间且用户随时可见。

### 2.2 设计

```tsx
// SessionCreditBar.tsx
export function SessionCreditBar({ sessionId }: { sessionId: string }) {
  const { usage } = useSessionUsage(sessionId);
  
  return (
    <div className="flex items-center justify-between px-4 py-2 bg-muted/50 border-y text-xs text-muted-foreground">
      <div className="flex items-center gap-4">
        <span className="flex items-center gap-1">
          <Flame className="w-3 h-3" />
          本次已消耗: {usage.totalCredits} 积分
        </span>
        <span className="flex items-center gap-1">
          <MessageSquare className="w-3 h-3" />
          {usage.totalTokens.toLocaleString()} tokens
        </span>
      </div>
      <span>{usage.modelBreakdown.length} 个模型调用</span>
    </div>
  );
}
```

### 2.3 实时更新

- 每次 LLM 响应返回 usage 后，前端累加显示
- 数据通过 WebSocket 或轮询获取（推荐 WebSocket）
- 刷新页面后从 API 重新聚合

## 3. 设置菜单 - 消费历史

### 3.1 位置

在设置对话框中新增「积分与消费」Tab：

```
设置
├── 账户
├── 外观
├── 语言
├── 积分与消费    ← 新增
└── 关于
```

### 3.2 页面结构

```tsx
export function BillingSettingsTab() {
  const { credits } = useAuth();
  const { transactions, hasMore, loadMore } = useTransactions();
  
  return (
    <div className="space-y-6">
      {/* 余额卡片 */}
      <div className="p-6 rounded-lg bg-gradient-to-r from-amber-50 to-orange-50 border border-amber-200">
        <div className="text-sm text-amber-700 mb-1">当前余额</div>
        <div className="text-3xl font-bold text-amber-800 flex items-center gap-2">
          <Diamond className="w-8 h-8" />
          {credits?.balance?.toLocaleString()}
          <span className="text-base font-normal text-amber-600">积分</span>
        </div>
        <div className="mt-4 flex gap-4 text-sm text-amber-600">
          <span>累计获得: {credits?.totalEarned}</span>
          <span>累计消费: {credits?.totalConsumed}</span>
        </div>
      </div>
      
      {/* 充值入口（预留） */}
      <div className="flex gap-3">
        <Button disabled>
          <Plus className="w-4 h-4 mr-2" />
          充值积分（即将上线）
        </Button>
      </div>
      
      {/* 消费记录列表 */}
      <div>
        <h3 className="text-lg font-semibold mb-4">消费记录</h3>
        <div className="space-y-2">
          {transactions.map(tx => (
            <div key={tx.id} className="flex items-center justify-between p-3 rounded-lg border hover:bg-muted/50 transition-colors">
              <div className="flex items-center gap-3">
                <div className={`w-8 h-8 rounded-full flex items-center justify-center ${
                  tx.type === 'consume' ? 'bg-red-100 text-red-600' :
                  tx.type === 'recharge' ? 'bg-green-100 text-green-600' :
                  'bg-blue-100 text-blue-600'
                }`}>
                  {tx.type === 'consume' ? <ArrowDown className="w-4 h-4" /> :
                   tx.type === 'recharge' ? <ArrowUp className="w-4 h-4" /> :
                   <Settings className="w-4 h-4" />}
                </div>
                <div>
                  <div className="font-medium">{tx.description}</div>
                  <div className="text-xs text-muted-foreground">
                    {formatDate(tx.createdAt)}
                  </div>
                </div>
              </div>
              <div className={`font-mono font-medium ${
                tx.amount < 0 ? 'text-red-600' : 'text-green-600'
              }`}>
                {tx.amount > 0 ? '+' : ''}{tx.amount}
              </div>
            </div>
          ))}
        </div>
        
        {hasMore && (
          <Button variant="ghost" className="w-full mt-4" onClick={loadMore}>
            加载更多
          </Button>
        )}
      </div>
    </div>
  );
}
```

### 3.3 消费记录筛选

支持按类型筛选：
- 全部
- 消费（consume）
- 充值（recharge）
- 调整（adjust）

## 4. 空状态与异常处理

### 4.1 新用户（无消费记录）

显示引导：
```
暂无消费记录
新用户赠送 500 积分，快去开始你的第一个会话吧！
[开始新会话] ← 按钮
```

### 4.2 积分不足时创建会话

显示错误提示：
```
积分不足，无法创建新会话
当前余额: 0 积分
[了解充值方式] ← 按钮（预留）
```

### 4.3 数据加载失败

```
积分数据加载失败
[重试]
```

## 5. 接口调用时机

| 场景 | 接口 | 时机 |
|------|------|------|
| 页面加载 | GET /api/billing/credits | 进入任意页面时 |
| 打开设置 | GET /api/billing/transactions | 切换到「积分与消费」Tab 时 |
| 会话中 | GET /api/billing/session/:id/usage | 进入会话页面时 + 每次 LLM 响应后 |
| 积分变动 | WebSocket push | 后端主动推送 |

## 6. 性能考虑

1. **Header 余额**: 全局获取一次，后续通过 WebSocket 增量更新
2. **消费记录**: 分页加载，首次 20 条
3. **会话消耗**: 本地累加 + 定期同步，减少 API 调用
4. **缓存策略**: credits 数据缓存 30 秒，transactions 不缓存
