## 1. 文档目标

本文只定义：

1. connector guide 体系所需数据表
2. 最短路径实现顺序
3. 任务清单

本文明确不再包含：

1. `platform skill` 复用设计
2. `sandbox skill sync` 接入
3. `resolvedSkills` 合并表

## 2. 数据建模原则

### 2.1 connector guide 是连接器域对象

guide 文本只属于连接器模块，不属于现有 skills 模块。

### 2.2 guide 是纯文本 revision

每个 revision 只保存三段文本：

1. `serverInstructionsMarkdown`
2. `guideReminderMarkdown`
3. `blockingRulesMarkdown`

### 2.3 运行时只读 published revision

draft 不进入运行时。

## 3. 新增数据表

## 3.1 `connector_guide_policies`

字段建议：

1. `id`
2. `connector_key`
3. `status`
   - `draft`
   - `active`
   - `archived`
4. `trigger_mode`
   - `on_attach`
   - `on_active_use`
   - `on_attach_and_active_use`
5. `description`
6. `published_revision_id`
7. `created_by`
8. `created_at`
9. `updated_at`

约束：

1. `unique(connector_key)`

## 3.2 `connector_guide_revisions`

字段建议：

1. `id`
2. `policy_id`
3. `version_number`
4. `status`
   - `draft`
   - `published`
   - `archived`
5. `server_instructions_markdown`
6. `guide_reminder_markdown`
7. `blocking_rules_markdown`
8. `notes`
9. `created_by`
10. `created_at`
11. `published_at`

约束：

1. `unique(policy_id, version_number)`

## 3.3 `task_session_connector_guides`

用途：

记录某 session 当前哪些 connector guides 已解析生效。

字段建议：

1. `id`
2. `task_session_id`
3. `connector_key`
4. `policy_id`
5. `revision_id`
6. `trigger_mode`
7. `resolved_at`

约束：

1. `unique(task_session_id, connector_key)`
2. `index(task_session_id)`

说明：

1. 这张表只记录 guide 生效关系
2. 不保存三段大文本全文，运行时全文从 revision 读取

## 4. 与现有模块的关系

### 4.1 `task_session_connector_bindings`

仍然是 connector attach 事实来源。

新增逻辑：

1. attach / detach 后重算 `task_session_connector_guides`

### 4.2 `altus-managed-prompt-service.ts`

新增逻辑：

1. 从 `task_session_connector_guides` 读取当前 session 生效的 guide
2. 注入 `Connector MCP Instructions`
3. 注入 `Relevant Connector Guides`

### 4.3 `altus-managed-tool-runtime.ts`

本轮最小闭环已包含 runtime 强约束：

1. 新增内建工具 `load_connector_guide`
2. 首次命中带 active guide 的 connector MCP tool 时先阻断
3. 调用 `load_connector_guide` 成功后，在当前 run 内放行该 connector 的 MCP tool

### 4.4 `platform skills`

无关系。

必须保持：

1. 不读取
2. 不写入
3. 不引用
