# 20260418_部署编排 Skill 自动挂载测试方案 [20260418-1612已采用]

## 1. 目标

验证部署相关请求会自动挂载 `deployment-orchestrator` skill，且在运行时实际调用部署工具时，也会基于 `autoActivation.toolNames` 自动补挂 skill；同时不影响非部署类消息或现有手动 skill 选择链路。

## 2. 覆盖范围

- `apps/api/src/services/platform-skill-seeds.ts`
- `apps/api/src/services/platform-skill-governance-options.ts`
- `apps/api/src/services/altus-managed-input-service.ts`
- `apps/api/src/services/altus-managed-tool-runtime.ts`
- `apps/api/scripts/verify-skill-governance-business.ts`
- `apps/admin_management/web/src/components/SkillManagementSection.tsx`
- `apps/api/tests/altus-managed-input-service.test.ts`
- `apps/api/tests/platform-skill-governance-options.test.ts`
- `apps/api/tests/altus-managed-tool-runtime.test.ts`

## 3. 用例

### 用例 1：部署请求自动挂载部署 skill

输入：

- content=`帮我部署当前项目`
- metadata 未显式提供 skill

断言：

- `metadata.skills` 自动包含 `deployment-orchestrator`
- `managedSkillContext` 自动包含 `deployment-orchestrator`

### 用例 2：重新部署 / 回滚 / 状态查询也自动挂载

分别验证：

- `帮我重新部署当前项目`
- `帮我回滚当前部署`
- `帮我查看部署状态`

### 用例 3：非部署消息不自动挂载

输入：

- `你好`
- `帮我写个网站`

断言：

- 不自动追加 `deployment-orchestrator`

### 用例 4：用户已手动选择时不重复注入

输入 metadata 已带 `deployment-orchestrator`

断言：

- 最终 `metadata.skills` 中该 skill 只出现一次

### 用例 5：部署工具调用时自动补挂 skill

输入：

- governance 中配置 `autoActivation.toolNames=['deploy_application']`
- runtime 实际执行 `deploy_application`

断言：

- 运行时会解析并同步对应 skill
- 后续轮次可把该 skill 当作 active skill 使用

### 用例 6：管理端治理字段必须来自受控枚举

断言：

- `systemRole` 改为下拉选择
- `autoActivation.triggers` 改为多选勾选
- `autoActivation.toolNames` 改为多选勾选
- 工具选项源和平台 managed tool definitions 一致

### 用例 7：业务脚本验证 deploy tool 自动挂载闭环

执行：

- 直接运行 `apps/api/scripts/verify-skill-governance-business.ts`

断言：

- 平台治理选项中包含 `deployment_orchestrator`
- 平台治理选项中包含 `deploy_application`
- 直接执行 `deploy_application` 时会自动挂载 `deployment-orchestrator`
