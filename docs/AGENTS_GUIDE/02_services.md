# 02 服务启动

- Web（用户端）
  - 目录：`apps/web`
  - 启动：`pnpm dev`
  - 访问：`http://localhost:3000`

- API（主平台）
  - 目录：`apps/api`
  - 启动：`pnpm dev`
  - 访问：`http://localhost:4000`

- 管理后台
  - 目录：`apps/admin_management`
  - 启动：`npm run dev`
  - Web：`http://localhost:5174`
  - API：`http://localhost:9310`

- 快速启动（仅 Web + API）
  - `start.bat`
