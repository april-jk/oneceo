**详情弹窗功能说明**：

1. **概览 Tab**
   - 显示用户积分概况

3. **使用明细 Tab**

   - 会话ID 可点击跳转「会话详情」页
   - 支持按模型、时间范围筛选

4. **趋势分析 Tab**
   - 近 7/30/90 天积分消耗趋势折线图
   - 近 7/30/90 天 Token 使用趋势图
   - 模型使用分布饼图

### 4.3 定价变更规则

- 同一模型同一时间只能有一条 active 记录
- 编辑定价 = 创建新记录 + 停用旧记录
- 历史定价保留，用于历史数据一致性
- **缓存比例由系统固定**：OpenAI 命中 50%，Anthropic 命中 10%/创建 125%
- 管理员只需配置基础输入/输出单价，缓存价自动计算

## 5. Tab 3: 平台统计看板

### 5.1 核心指标卡片（第一行）

```
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 今日消耗      │ │ 今日Tokens   │ │ 今日会话数   │ │ 活跃用户     │
│ 125,000      │ │ 2,500,000    │ │ 450          │ │ 89           │
│ 积分         │ │ tokens       │ │ 个           │ │ 人           │
│ ≈¥1,250      │ │              │ │              │ │              │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

**人民币换算说明**：
- 在积分下方显示对应人民币金额（按 100 积分 = ¥1 换算）
- 鼠标悬停显示换算公式：125,000 积分 × ¥0.01/积分 = ¥1,250
- 管理员可配置兑换比例（默认 100:1）

### 5.2 核心指标卡片（第二行 - 缓存统计）

```
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 缓存节省      │ │ 缓存命中率   │ │ 缓存命中Tokens│ │ 缓存创建Tokens│
│ 35,000       │ │ 31.2%       │ │ 500,000      │ │ 200,000      │
│ 积分         │ │             │ │ tokens       │ │ tokens       │
│ ≈¥350        │ │             │ │ 节省¥500     │ │ 成本¥200     │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

**缓存统计说明**：
- 缓存节省：相比无缓存计费节省的积分总额
- 缓存命中率：cachedPromptTokens / totalPromptTokens
- 缓存命中 Tokens：实际按低价计费的 token 数
- 缓存创建 Tokens：Anthropic 模式下缓存写入的 token 数
- 所有金额支持人民币换算显示

### 5.3 趋势图表

时间范围选择：[今日] [本周] [本月] [自定义]

**图表 1: 积分消耗趋势（双轴折线图）**
- X 轴: 时间（小时/天）
- 左 Y 轴: 消耗积分（折线）
- 右 Y 轴: 对应人民币金额（虚线，按配置比例）
- 图例: 实际消耗 / 换算金额

**图表 2: Token 使用趋势（堆积面积图）**
- X 轴: 时间
- Y 轴: tokens 数量
- 堆积项: 非缓存输入 / 缓存命中输入 / 缓存创建输入 / 输出

**图表 3: 缓存效果趋势（组合图）**
- X 轴: 时间
- 柱状: 总输入 Tokens
- 折线: 缓存命中率 (%)
- 折线: 缓存节省积分

### 5.6 平台收支概览

```
┌─────────────────────────────────────────┐
│ 平台收支概览                             │
├─────────────────────────────────────────┤
│ 今日收入（充值）: +¥5,000 (500,000 积分) │
│ 今日支出（消费）: -¥1,250 (125,000 积分) │
│ 今日净收益: +¥3,750                     │
│ 缓存节省成本: -¥350                      │
│ 实际净收益: +¥4,100                      │
│                                          │
│ [查看充值明细] [查看消费明细]             │
└─────────────────────────────────────────┘
```

**收支说明**：
- 收入：用户充值获得的人民币（后续对接支付系统）
- 支出：用户 LLM 调用消耗的积分对应的人民币成本
- 缓存节省成本：因缓存机制节省的调用成本
- 实际净收益 = 收入 - 支出 + 缓存节省（缓存降低了平台成本）

## 7. 权限控制

只有超级管理员可以：
- 调整用户积分
- 修改模型定价
- 查看平台统计

普通管理员（如果有的话）只能：
- 查看用户积分列表
- 查看 Token 使用明细

## 8. 数据导出

### 8.1 导出格式

CSV 格式：
```csv
time,user_email,session_id,model,prompt_tokens,completion_tokens,total_tokens,credits_consumed
2026-04-22 14:30:00,zhang@example.com,abc123,gpt-4o,2000,800,2800,120
```

### 8.2 导出范围

- 当前筛选条件下的全部数据
- 最大导出 10,000 条（防止内存溢出）
- 超出时提示缩小时间范围

## 9. 实时刷新

- 页面默认 30 秒自动刷新一次
- 提供「暂停刷新」按钮
- 手动操作后（如调整积分）立即刷新
