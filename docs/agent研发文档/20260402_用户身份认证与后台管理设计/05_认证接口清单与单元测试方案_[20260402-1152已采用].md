## 3. 核心断言

### 3.1 用户态 API

1. 注册成功后返回 `success: true`、用户公开信息，并写入 `app_session_id` cookie
2. 注册失败时返回 `400`，不写入成功 cookie
3. 登录成功后返回用户公开信息，并写入 `app_session_id` cookie
4. 登录失败时返回 `400`
5. `/me` 在无 cookie 时返回 `401`
6. `/me` 在有效 cookie 且中间件已解析用户后返回当前用户
7. 登出会清理 cookie，并调用会话注销逻辑

### 3.2 API 内部管理员认证

1. 未携带或携带错误 `x-oneceo-internal-token` 时返回 `403`
2. 内部管理员登录成功返回 `sessionToken` 和 `adminUser`
3. 内部管理员登出成功返回 `ok: true`
4. 会话解析成功返回 `adminUser`
5. 会话失效时返回 `401`

### 3.3 管理端代理接口

1. 管理员登录成功时写入 `admin_session_id` cookie，并只返回公开管理员信息
2. 管理员 `/me` 在无 cookie 时返回 `401`
3. 管理员 `/me` 在有效 cookie 时返回公开管理员信息
4. 管理员登出会清理 `admin_session_id` cookie，并透传调用后端登出

### 3.4 用户态任务会话与 workspace 接口

1. 会话创建时数据库归属必须写入当前登录用户 `userId`
2. 会话列表在未登录时返回 `401`
3. 会话列表只返回当前用户拥有的会话，不能泄漏其他用户 session
4. workspace 目录读取在跨用户访问时返回 `403`
5. 会话列表缓存必须按用户隔离，不能继续共享全局缓存

### 3.5 用户态连接器个人配置接口

1. `/api/connectors/me` 在未登录时返回 `401`
2. `/api/connectors/me` 只能返回当前用户的 profiles
3. 创建连接器 profile 时必须把当前用户 `userId` 传入服务层

### 3.6 用户态深水区会话接口

1. 所有用户态会话接口在未登录时必须返回 `401`
2. 所有 owner 路由在跨用户访问时必须返回 `403`
3. `skills`、`runtime-config`、`draft session` 必须从当前登录用户身份派生，不能再依赖浏览器伪身份
4. `title/favorite/detail/messages/intent/task-description/execution-plan/delete` 必须先校验 `session.userId`
5. `attachments`、`deliverables`、`runtime`、`session connectors`、`debug`、`deployment`、`database rows` 必须先校验会话连接器 owner 边界
6. `workspace/raw` 与 `opencode/events` 不能绕过 owner 校验直接读取 runtime

### 3.7 Altus managed 用户态接口

1. `inputs`、`runs/latest` 在未登录时必须返回 `401`
2. `inputs`、`runs`、`stop` 必须把当前用户 `userId` 透传到 service
3. `run stream` 必须按当前登录用户校验 `run.sessionId -> session.userId`
4. `run stream` 不再接受查询参数伪造 `userId`

## 4. 单测策略

### 4.1 技术路线

1. 统一使用仓库现有 `node:test` + `tsx --test`
2. 路由测试使用最小 Express app + 随机端口 HTTP 请求
3. 不接真实数据库，改为 stub `service` 或 `connector`
4. 对 cookie 通过响应头 `set-cookie` 做断言

## 5. 通过标准

1. 所有接口至少覆盖一条成功路径
2. 所有鉴权接口至少覆盖一条未授权路径
3. 所有会话接口至少覆盖一条会话失效路径
4. 所有登录/登出接口必须断言 cookie 写入或清理行为
5. 用户态业务接口需要覆盖全部已暴露 HTTP 路由，至少有一条成功或拒绝路径
6. 对 owner 路由，必须至少覆盖一条跨用户拒绝路径
