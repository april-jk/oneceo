# 2026-04-18 admin_management 界面收敛优化方案 [20260418-0115已采用]

## 1. 背景

在 `admin_management` 近期多轮重构后，管理后台已经具备统一的控制台骨架，但真实巡检仍暴露出一批高频使用问题：

1. 顶部浮动栏信息过载，管理员身份在顶栏和侧栏重复出现；
2. `对话管理` 的筛选条在常见桌面宽度下过长，首屏列表被明显下压；
3. `Sandbox 管理` 的运行时列表行操作过重，主次动作不清晰；
4. 移动端下顶栏按钮会被全宽样式放大，首屏高度被头部吞掉；
5. 登录表单缺少浏览器自动填充和密码管理器所需的基础语义。
6. `用户详情` 首屏在弹窗头部与概览卡内重复展示用户名和邮箱，首屏信息层级发散。
7. `Sandbox 管理` 列表行中的复制按钮过密，扫描路径被频繁打断。
8. 顶栏“刷新”在 `用户管理 / 技能管理 / Connector Guide / OSAC 版本` 中没有真正落到各自页面的数据加载逻辑。
9. `技能管理 / Connector Guide / OSAC 版本` 的筛选与刷新语义不一致，局部按钮命名和实际行为对不上。
10. 页面状态仍主要停留在内存里，刷新后不能直接回到 `模块 + 关键筛选 + 已打开详情`。
11. `技能管理 / Connector Guide / OSAC 版本` 仍缺少各自的 URL 深链状态。
12. `Connector Guide` 的 revision 切换依赖表格单元格点击，键盘用户难以发现和操作。
13. 管理后台入口 JS chunk 已接近 934 kB，首次打开会一次性加载用户、技能、Connector Guide、OSAC、KVM 等模块代码。
14. 当前字体和卡片间距仍偏展示型，大量标题、KPI、表格单元占据过多纵向空间，不符合 AWS / Cloudflare 这类云控制台的紧凑密度。

本轮不做整站重新设计，只做一轮高收益的界面收敛。

## 2. 目标

1. 压缩顶栏信息密度，让标题、状态、动作三层更稳定；
2. 将 `对话管理` 的筛选从单行硬塞收敛为更可扫读的两层结构；
3. 降低 `Sandbox 管理` 列表行内操作噪音，让主动作更明确；
4. 修正移动端顶栏按钮被拉成整宽的问题；
5. 补齐登录表单基础语义，不改变登录链路。
6. 去掉 `用户详情` 首屏重复身份信息，让概览卡更聚焦状态与事实。
7. 保留 Sandbox 标识复制能力，但把复制动作从行内显著位置收回到二级菜单。
8. 让顶栏刷新真正刷新当前页面，而不是在部分模块里只做空操作。
9. 统一“同步列表 / 应用筛选 / 重置筛选”的语义边界，减少同页重复刷新动作。
10. 让高价值运行管理页面具备可分享的 URL 深链状态。
11. 把 `技能管理 / Connector Guide / OSAC 版本` 也纳入 URL 深链恢复范围。
12. 让 `Connector Guide` revision 切换具备明确的键盘可达入口。
13. 将非首屏模块改成按需加载，降低入口 bundle 体量。
14. 将管理后台视觉密度收敛到紧凑控制台风格，主要文本使用 12px / 14px 两档。

## 4. 方案

### 4.1 顶栏收敛

1. 顶栏元信息只保留：
   - 最后更新时间
   - 当前模块服务状态
2. 当前管理员姓名继续只放在侧栏底部，不再在顶栏重复出现。
3. 移动端下 `刷新 / 退出` 继续保留，但不再被通用按钮规则拉成整宽。

### 4.2 对话管理筛选条

1. 保留现有筛选能力，不删字段。
2. 将筛选区拆成：
   - 主筛选行：搜索、状态/阶段、用户、处理方式、重置
   - 次筛选行：更新开始日期、更新结束日期
3. 筛选命中说明继续保留在筛选区下方，不和列表头竞争。

### 4.3 Sandbox 行内动作降噪

1. 运行时列表行操作统一收成：
   - `详情`
   - 当前主动作（`开机` 或 `暂停`）
   - `更多`
2. `关机` 从主动作区移入 `更多` 菜单。
3. `重启 / 归档` 继续保留在 `更多` 菜单中。

### 4.4 登录表单语义补齐

1. 登录名输入框补充：
   - `name="username"`
   - `autoComplete="username"`
   - `autoCapitalize="none"`
   - `autoCorrect="off"`
   - `spellCheck={false}`
2. 密码输入框补充：
   - `name="password"`
   - `autoComplete="current-password"`

### 4.5 用户详情首屏去重

1. `用户详情` 弹窗头部继续承担用户名与邮箱展示。
2. `概览` 页左侧卡片不再重复显示用户名与邮箱。
3. 左侧卡片顶部改成：
   - `账号摘要`
   - 当前状态与登录状态 badge
   - 一句说明性摘要
4. Tab 条与弹窗头部贴合，避免标题区、标签区、正文区之间出现割裂留白。
5. 首屏优先展示：
   - 当前登录
   - 上次登录
   - 最近访问
   - 用户 ID / 最近来源 IP / 账号状态 / 登录状态

### 4.6 Sandbox 复制动作收敛

1. 运行时列表行内移除 `复制` 按钮。
2. `更多` 菜单追加：
   - `复制会话 ID`
   - `复制 Sandbox ID`
3. 行内仍保留：
   - 会话跳转入口
   - 截断后的 Sandbox ID 展示
4. 详情页和其他弹层中的复制能力不受影响。

### 4.7 工作台动作语义统一

1. 顶栏主动作统一定义为 `刷新当前页`，职责是刷新当前一级模块的核心数据。
2. 对 `用户管理 / 技能管理 / Connector Guide / OSAC 版本`：
   - 顶栏刷新不再停留在空操作，而是委派到各自页面内部的真实加载函数。
   - 页面内部的列表同步动作统一叫 `同步列表`，只表示重新向服务端拉取当前页数据。
3. 筛选语义拆成两类：
   - `对话管理 / 用户管理 / 审计日志` 继续保留显式 `应用筛选`
   - `技能管理 / Connector Guide / OSAC 版本` 的输入项保持即时生效，不再额外放一个名不副实的“应用筛选”刷新按钮
4. 即时生效筛选页统一补 `重置筛选`，方便快速回到默认状态。
5. 顶栏 `最后更新` 需要使用当前页面自己的数据时间，不再回退到其他模块的时间戳。

### 4.8 URL 深链状态

1. 通过 query string 同步当前一级模块：`section`。
2. 对运行管理中的高价值页面同步关键状态：
   - `对话管理`：搜索、状态/阶段、用户、处理方式、日期、当前会话
   - `Sandbox 管理`：当前子页签、运行时筛选、已打开的 Sandbox 详情
   - `用户管理`：已应用筛选、排序、当前打开的用户详情页签
   - `审计日志`：已应用筛选
3. URL 只保留当前一级模块相关的查询参数，避免把其他模块的残留状态带进分享链接。
4. 刷新页面后，后台应尽量恢复到同一工作上下文。

### 4.9 平台配置页深链补齐

1. `技能管理` 同步：
   - 搜索、状态、分类
   - 二级筛选视图
   - 当前技能详情、页签、版本
2. `Connector Guide` 同步：
   - connector、状态、搜索
   - 当前 policy
   - 当前 revision
3. `OSAC 版本` 同步：
   - 当前 tab
   - 搜索词
   - 已打开的版本详情

### 4.10 Connector Guide Revision 可达性

1. revision 列表取消把点击行为绑在 `<td>` 上。
2. 第一列提供明确的“查看版本”按钮，作为 revision 切换入口。
3. 当前选中 revision 需要有可见的 focus / active 状态。

### 4.11 模块级懒加载

1. 将 `用户管理 / 技能管理 / Connector Guide / OSAC 版本 / KVM 管理` 改为 `React.lazy` 动态加载。
2. 将这些模块的 URL 状态类型和默认值移动到轻量共享文件，避免 `App.tsx` 为读取默认状态而静态拉入整页组件。
3. 使用现有 `loading-state` 作为 `Suspense` fallback，不新增视觉体系。
4. 保持当前 `activeSection` 分支不变，不引入 React Router 或新的状态管理库。
5. 首屏默认仍然进入 `Sandbox 管理`；只有切换到对应模块时才下载其组件 chunk。
6. 第二阶段继续拆入口包里的低耦合页面，优先将 `智能体管理` 迁出 `App.tsx`，再处理耦合更高的 `Sandbox 管理 / 对话管理`。

### 4.12 紧凑字体与密度

1. 参考 AWS Cloudscape 的控制台字体层级：
   - 正文和主要控件以 14px 为主；
   - 标签、元信息、表格辅助信息以 12px 为主；
   - 不把常规可读文本压到 12px 以下。
2. 将后台从“展示型标题层级”收敛为“运维控制台层级”：
   - 顶栏标题、面板标题、弹窗标题降低字号；
   - KPI 数字、hero 标题降低字号；
   - 表格、按钮、输入框、状态标签统一到 12px / 14px；
   - 卡片、表格、导航、表单间距同步压缩。
3. 保持登录页略高一级视觉层级，但仍压缩输入框、按钮和说明字号。
4. 不更换主题色，不引入新的设计系统库。

## 5. 实施约束

1. 不新增新视觉体系，只在现有变量和组件样式内收敛。
2. 不引入新的状态管理库或路由库。
3. 不修改管理端接口语义。
4. 保持 `Sandbox 管理`、`对话管理` 的数据获取逻辑不变。
5. 不引入路由库；URL 状态使用原生 query string 与 history API 完成。
6. 懒加载只改变代码加载时机，不改变页面权限、数据请求和刷新语义。
7. 字体收敛不能影响表单可点击区域、表格横向滚动和详情弹窗可读性。

## 6. 验收标准

1. 顶栏不再重复显示管理员姓名。
2. `对话管理` 在 `1280px` 左右宽度下，筛选区不再把日期字段挤出主工作区。
3. `Sandbox 管理` 列表每行默认只显示 `详情 + 主动作 + 更多`。
4. `390px` 左右宽度下，顶栏按钮不再整宽堆叠。
5. 登录表单可被浏览器自动识别用户名和密码字段。
6. `用户详情` 首屏不再在头部和概览卡内重复出现用户名与邮箱。
7. `用户详情` 中的 Tab 条与标题区保持紧贴，不再像独立悬浮区块。
8. `Sandbox 管理` 列表行内不再出现密集 `复制` 按钮，但 `更多` 菜单仍可复制关键标识。
9. 顶栏 `刷新当前页` 在 `用户管理 / 技能管理 / Connector Guide / OSAC 版本` 中能触发真实数据刷新。
10. `技能管理 / Connector Guide / OSAC 版本` 的本地列表同步动作统一命名为 `同步列表`，即时筛选页不再保留多余的“应用筛选”按钮。
11. 顶栏 `最后更新` 在 `技能管理 / Connector Guide / OSAC 版本` 中显示的是当前模块自己的更新时间。
12. 刷新页面后，可直接回到当前运行管理模块的关键筛选和已打开详情。
13. `技能管理 / Connector Guide / OSAC 版本` 刷新页面后，可恢复各自的关键筛选与已打开详情。
14. `Connector Guide` revision 列表可通过键盘聚焦并切换版本。
15. 构建产物中应出现按模块拆分的 JS chunk，入口 JS chunk 体量低于懒加载前的约 934 kB。
16. 主要控件、表格、状态标签和元信息默认落在 12px / 14px 字体层级内。
17. 常见桌面宽度下首屏可见信息量应提升，视觉上更接近云服务控制台的紧凑工作台。
