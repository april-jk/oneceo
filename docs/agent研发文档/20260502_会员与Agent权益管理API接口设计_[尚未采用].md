# 20260502 会员与Agent权益管理API接口设计 [尚未采用]

## 1. 设计目标

本文件定义会员体系的用户侧查询接口、管理侧配置接口和任务创建校验接口，保证前端展示、后台配置和服务端强校验三者一致。

## 2. 认证与权限

1. 用户侧接口：仅允许登录态用户访问
2. 管理侧接口：仅允许管理员访问
3. 任务创建校验：按用户态登录态执行

## 3. 用户侧接口

### 3.1 `GET /api/membership/me`

返回当前用户的会员信息。

返回建议：

- 当前会员类型
- 状态
- 到期时间
- 当前可用 Agent tier
- 默认权益摘要
- 是否可用 `lite/pro/max`

### 3.2 `GET /api/membership/plans`

返回可见会员类型列表。

用途：

- 会员卡片展示
- 权益矩阵渲染
- Agent 选择器提示

### 3.3 `GET /api/membership/agent-availability`

返回当前用户可用的 Agent 范围。

返回建议：

- `allowedAgentLevels`
- `highestAllowedTier`
- `blockedReasons`

## 4. 管理侧接口

### 4.1 会员类型

1. `GET /api/internal/membership/plans`
2. `POST /api/internal/membership/plans`
3. `PUT /api/internal/membership/plans/:id`
4. `POST /api/internal/membership/plans/:id/disable`

### 4.2 用户会员

1. `GET /api/internal/membership/users`
2. `GET /api/internal/membership/users/:userId`
3. `PUT /api/internal/membership/users/:userId/assign`
4. `PUT /api/internal/membership/users/:userId/expire`

### 4.3 权益发放与审计

1. `POST /api/internal/membership/users/:userId/grant-credits`
2. `GET /api/internal/membership/audit-logs`

## 5. 任务创建校验接口

以下接口不一定新增路径，但必须挂接权限判定：

1. `POST /api/task-creation/sessions`
2. `POST /api/task-creation/sessions/:id/start`
3. `POST /api/task-creation/sessions/:id/switch-agent`

## 6. 接口返回约定

统一响应建议包含：

- `success`
- `data`
- `error`
- `code`

错误码建议：

- `membership_required`
- `membership_level_forbidden`
- `membership_expired`
- `membership_plan_inactive`
- `membership_grant_conflict`

## 7. 幂等与一致性

1. 会员发放接口必须支持幂等键
2. 分配用户会员接口应避免重复补发
3. `PUT /expire` 只能把活跃会员改成失效，不应删记录

## 8. 验证规则

1. 会员类型 code 不可重复
2. Agent tier 必须是 `lite/pro/max`
3. 默认积分必须是非负整数
4. 到期时间不能早于开始时间
