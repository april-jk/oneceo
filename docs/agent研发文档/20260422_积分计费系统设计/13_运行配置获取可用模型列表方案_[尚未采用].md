# 运行配置获取可用模型列表方案

> 状态：[20260427-1547已采用]

## 需求

在运行配置弹窗中增加"获取可用模型"功能，使用已保存的 Token 访问上游接口（如 `https://dashscope.aliyuncs.com/compatible-mode/v1/models`），获取并展示可用模型列表。

## 设计原则

1. **安全第一**：
   - 不暴露 API Token 到前端
   - 使用后端代理调用上游接口
   - 只返回安全的模型列表信息

2. **通用支持**：
   - 支持任何 OpenAI-compatible 的 `/v1/models` 接口
   - 不限于 dashscope，支持所有配置的运行入口

3. **简洁易用**：
   - 一键获取，无需额外配置
   - 模型列表可复制，方便填入运行配置

## 接口设计

### 后端新增接口

```
POST /api/internal/billing/runtime-config/models
```

**请求体：**
```json
{
  "key": "agent.pro"
}
```

**成功响应：**
```json
{
  "success": true,
  "data": {
    "key": "agent.pro",
    "models": [
      { "id": "qwen3-max-2026-01-23", "object": "model", "created": 1234567890, "owned_by": "alibaba" },
      { "id": "qwen-plus", "object": "model", "created": 1234567890, "owned_by": "alibaba" }
    ],
    "latencyMs": 234,
    "checkedAt": "2026-04-27T14:00:00.000Z"
  }
}
```

**错误响应：**
```json
{
  "success": false,
  "error": "API Token 未配置"
}
```

### 安全约束

1. 请求体只接受 `key` 字段，其他字段返回 400
2. 使用已保存的运行配置（env 中的 baseUrl + apiKey）调用上游
3. 上游响应只保留 `id`, `object`, `created`, `owned_by` 字段
4. 上游错误脱敏后返回，不暴露敏感信息

## 前端设计

### 弹窗位置

在运行配置编辑弹窗（`runtimeFormOpen`）和测试弹窗（`runtimeTestModalOpen`）中都增加获取模型功能：

1. **运行配置弹窗**：在"模型名称"输入框旁增加"获取可用模型"按钮
2. **测试弹窗**：在"响应详情"下方增加"可用模型列表"区域

### UI 元素

- **获取按钮**：`获取可用模型列表`
- **加载状态**：`获取中...`
- **模型列表**：卡片式展示，显示 model id 和 owned_by
- **点击复制**：点击模型名可复制到剪贴板
- **空状态**：`未获取到可用模型` 或 `请先配置 API Token`

### 交互流程

1. 用户点击"获取可用模型列表"
2. 显示加载状态
3. 后端使用已保存的 token 调用上游 `/v1/models`
4. 返回模型列表，前端展示
5. 用户点击模型名复制，粘贴到模型输入框

## 实现步骤

1. **后端**：

   - `billing-management-routes.ts` 新增代理

2. **前端**：
   - `BillingManagementSection.tsx` 新增状态和获取函数
   - 在运行配置弹窗中添加获取按钮和模型列表
   - 添加复制功能和提示

3. **样式**：
   - 在 `styles.css` 添加模型列表卡片样式

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| Token 未配置 | 提示"请先配置 API Token" |
| Base URL 未配置 | 提示"请先配置接口地址" |
| 上游接口不支持 /models | 提示"当前接口不支持获取模型列表" |
| 上游鉴权失败 | 脱敏后提示"鉴权失败，请检查 Token" |
| 上游超时 | 提示"获取超时，请检查网络" |

## 安全审查

- [x] Token 不在前端暴露
- [x] 使用已保存配置，不接受用户传入的 token/baseUrl
- [x] 上游错误脱敏处理
- [x] 请求体严格限制只接受 key
- [x] 响应只包含安全的模型元数据
