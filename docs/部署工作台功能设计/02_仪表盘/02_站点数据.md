# 仪表盘 / 站点数据

## 1. 功能目标

“站点数据”视图用于承接应用发布后的访问与分析信息，布局参考 Manus 的站点分析页。

目标是回答：

- 站点是否公开
- 最近访问情况如何
- 哪些页面被访问最多
- 流量从哪里来
- 用户主要来自哪些地区和设备

## 2. 顶部结构

建议页面顶部由三块组成：

### 2.1 站点头部信息

展示：

- logo
- 站点名称
- 主访问地址
- 文档按钮
- 打开网站按钮

### 2.2 公开状态卡

展示：

- 当前访问权限状态，例如“公开”
- 状态说明，例如“任何人都可以访问”
- `管理访问权限` 按钮

### 2.3 分析工具条

展示：

- 时间范围选择器
- 筛选器按钮
- 刷新按钮

## 3. 分析内容结构

站点数据主内容建议拆成五块：

### 3.1 指标总览

指标卡建议为：

- 页面浏览量
- 访问量
- 访客
- 持续时间
- 跳出率

说明：

- 没有真实数据时全部显示 `0` 或 `没有数据`
- 不能伪造增长百分比

### 3.2 浏览最多的页面

字段建议：

- 页面路径
- 页面标题
- 访客数

### 3.3 引荐来源

字段建议：

- referrer/source
- 访客数

### 3.4 地区

视图建议：

- 列表
- 地图

字段建议：

- 国家/地区
- 访客数

### 3.5 设备

视图建议：

- 浏览器
- 操作系统
- 设备

字段建议：

- 分类名称
- 访客数

## 4. 数据要求

站点数据必须有真实统计来源。

在没有分析管道之前：

- 保留结构
- 明确显示“没有数据”
- 支持空态展示

不应做的事：

- 不应伪造访问统计
- 不应把部署历史混入站点分析

## 5. 计划设计方式

### 当前阶段

- 先把站点数据视图定义完整
- 采用 Manus 风格的头部 + 分析布局
- 所有分析块都支持空态

### 下一阶段

- 接入真实埋点与统计聚合
- 支持时间范围切换
- 支持来源、地区、设备维度分析
- 支持后续文档与站点分析联动

## 6. 建议的数据模型

后续建议至少包含：

- `siteSummary`
- `trafficMetrics`
- `topPages`
- `topReferrers`
- `geoBreakdown`
- `deviceBreakdown`
- `accessPolicy`

## 7. 审核点

- 站点数据是否按这套 Manus 风格继续推进。
- `文档` 按钮是否需要真实绑定到站点说明文档。
- `管理访问权限` 是否应该尽快进入第一批可实现能力。
